# Portfolio Reader — 持仓自动读取与更新

## 核心能力

1. **自动读取持仓** — 直接读取共享 JSON 文件获取最新持仓，无需手动翻 Issue
2. **自然语言交易更新** — 用户只需说"我买了1000份半导体ETF，1.65元"，agent 自动更新持仓和现金
3. **数据共享与隔离** — 同一工作组内所有 agent 共享同一份持仓数据；不同工作组数据完全隔离
4. **交易记录追踪** — 自动记录最近10次买卖操作，随时可查

## 数据存储

持仓数据存储在工作组级别的共享路径：

```
~/.agents/portfolio-reader/data/<workspace_id>/portfolio.json
```

- **同一工作组**：所有 agent 读写同一份 `portfolio.json`，数据实时共享
- **不同工作组**：每个 workspace_id 对应独立的数据目录，互不影响
- **workspace_id 推断**：优先从环境变量 `MULTICA_WORKSPACE_ID` 获取；其次从当前 workdir 路径中匹配 UUID 格式的 workspace ID；都无法获取时使用 `"default"`

## JSON 数据格式

```json
{
  "last_updated": "2025-01-15 14:30:00",
  "cash": 50000.00,
  "holdings": [
    { "code": "512480", "name": "半导体ETF", "shares": 1000, "cost_price": 1.6500 },
    { "code": "510300", "name": "沪深300ETF", "shares": 2000, "cost_price": 4.8000 }
  ],
  "transactions": [
    { "time": "2025-01-15 14:30:00", "type": "buy", "code": "512480", "name": "半导体ETF", "shares": 1000, "price": 1.6500, "amount": 1650.00 }
  ]
}
```

**字段说明**：
- `last_updated`：最后更新时间，格式 `YYYY-MM-DD HH:MM:SS`，每次写入时更新为当前时间
- `cash`：可用资金（浮点数，精确到2位小数）
- `holdings`：持仓列表
  - `code`：标的代码（如 "512480"）
  - `name`：标的名称（如 "半导体ETF"）
  - `shares`：持有份额（整数）
  - `cost_price`：成本价（浮点数，精确到4位小数）
- `transactions`：最近交易记录（最多保留10条，超出时只保留最新的10条）
  - `time`：交易时间
  - `type`：交易类型 `"buy"` 或 `"sell"`
  - `code`：标的代码
  - `name`：标的名称
  - `shares`：交易份额
  - `price`：成交价格
  - `amount`：成交金额（精确到2位小数）

## 操作指引

**通用原则**：
- 所有操作都是「读取 JSON → 修改内存中的数据 → 写回 JSON」的三步流程
- 写入前必须确保目录存在（`mkdir -p`）
- 每次写入都更新 `last_updated` 为当前时间
- 比较标的代码时，忽略后缀差异（`.SZ` / `.SH` / `.US` / `.OF`），只比较核心代码部分

---

### 1. 读取持仓

**操作**：直接读取 `portfolio.json` 文件内容。

如果文件不存在，视为空持仓（cash=0, holdings=[], transactions=[]）。

**展示格式**（供用户查看时使用）：

```
📋 当前持仓概览

| 标的 | 代码 | 份额 | 成本价 | 成本金额 |
|------|------|------|--------|----------|
| 半导体ETF | 512480 | 1,000 | 1.6500 | 1,650.00 |
| 沪深300ETF | 510300 | 2,000 | 4.8000 | 9,600.00 |

📈 持仓成本合计：11,250.00 元
💰 剩余可用资金：50,000.00 元
📊 总资产估算：61,250.00 元（持仓成本 + 可用资金）
🕐 最后更新：2025-01-15 14:30:00
```

---

### 2. 买入/加仓

当用户说类似以下内容时：
- "我买了1000份半导体ETF，1.65元"
- "加仓510300，2000份，4.8元"

**操作步骤**：

1. 读取当前 portfolio.json（不存在则用默认空数据）
2. 在 holdings 中查找是否已有该标的（忽略 `.SZ`/`.SH`/`.US`/`.OF` 后缀比较代码）
3. **如果已有**：
   - 新成本价 = (原份额 × 原成本价 + 新份额 × 买入价) / (原份额 + 新份额)，四舍五入到4位小数
   - 新份额 = 原份额 + 新份额
   - 更新 name（如果提供了新的名称）
4. **如果没有**：
   - 新增一条 holding：`{ "code": "<代码>", "name": "<名称>", "shares": <份额>, "cost_price": <价格> }`
5. 扣减现金：`cash -= 份额 × 价格`，四舍五入到2位小数
6. 追加交易记录到 transactions：`{ "time": "<当前时间>", "type": "buy", "code": "<代码>", "name": "<名称>", "shares": <份额>, "price": <价格>, "amount": <金额> }`
7. 如果 transactions 超过10条，只保留最新的10条
8. 更新 `last_updated`，写回文件

**输出示例**：`✅ 买入 半导体ETF（512480）1000份 @ 1.65元，花费 1,650.00 元`

---

### 3. 卖出/减仓

当用户说类似以下内容时：
- "卖了1000份纳指ETF，1.38元"
- "减仓510300，500份，4.75元"

**操作步骤**：

1. 读取当前 portfolio.json
2. 在 holdings 中查找该标的
3. 如果未找到，提示 `❌ 未找到 <代码> 的持仓记录`，停止操作
4. 如果持仓份额不足，提示 `❌ 持仓不足：<名称>（<代码>）仅有 <实际份额>份，尝试卖出 <卖出份额>份`，停止操作
5. 扣减份额：`shares -= 卖出份额`
6. 增加现金：`cash += 卖出份额 × 价格`，四舍五入到2位小数
7. 如果份额变为0，从 holdings 中移除该条目（清仓）
8. 追加交易记录到 transactions：`{ "time": "<当前时间>", "type": "sell", "code": "<代码>", "name": "<名称>", "shares": <份额>, "price": <价格>, "amount": <金额> }`
9. 如果 transactions 超过10条，只保留最新的10条
10. 更新 `last_updated`，写回文件

**输出示例**：`✅ 卖出 纳指ETF（513100）1000份 @ 1.38元，回笼 1,380.00 元` 或 `✅ 清仓 纳指ETF（513100），回笼 1,380.00 元`

---

### 4. 查看最近交易记录

**操作**：读取 portfolio.json，展示 transactions 数组（按时间倒序）。

**展示格式**：

```
🔄 最近交易记录（最多10条）

| 时间 | 类型 | 标的 | 代码 | 份额 | 价格 | 金额 |
|------|------|------|------|------|------|------|
| 2025-01-15 14:30:00 | 🟢 买入 | 半导体ETF | 512480 | 1,000 | 1.6500 | 1,650.00 |
```

---

### 5. 更新可用资金

**操作步骤**：

1. 读取 portfolio.json
2. 设置 `cash` 为指定金额
3. 更新 `last_updated`，写回文件

**输出示例**：`✅ 可用资金已更新为 50,000.00 元`

---

### 6. 从 Issue 导入持仓

当用户需要从已有 Issue 文本初始化持仓时：

**操作步骤**：

1. 读取 portfolio.json，如果已有持仓数据，提示用户需先清除
2. 从用户提供的文本中，用以下正则匹配持仓行：
   - 模式：`(.+?)[（(](\d{6})[）)]\s*\|\s*([\d,]+)份\s*\|\s*成本([\d.]+)元`
   - 提取：名称、代码、份额（去掉逗号转整数）、成本价（转浮点）
3. 从文本中匹配可用资金：`剩余可用资金共([\d,]+)元`（去掉逗号转浮点）
4. 写回文件

---

## 初始化

如果 `portfolio.json` 文件不存在，使用以下默认数据创建：

```json
{
  "last_updated": null,
  "cash": 0,
  "holdings": [],
  "transactions": []
}
```
