# 催化剂日历

构建和维护覆盖范围内的催化剂日历——包括财报日期、行业会议、产品发布、监管决策和宏观事件。帮助优先分配注意力、提前布局。

## 工作流程

### 步骤 1：定义覆盖范围

需要用户提供以下信息：

- 需要追踪的公司列表（代码或名称）
- 行业/板块聚焦
- 是否包含宏观事件？（央行会议、经济数据、监管截止日期）
- 时间范围（未来2周、1个月、1季度）

### 步骤 2：收集催化剂

**数据来源**：催化剂信息由用户自行准备，或通过其他 skill 获取。本 skill 不自动拉取数据。

对每家公司，识别以下类型的事件：

**财报与财务事件**
- 季度财报日期和时间（盘前/盘后）
- 年度股东大会
- 投资者日 / 分析师日
- 资本市场日
- 债券到期 / 再融资日期

**公司事件**
- 产品发布或公告
- FDA审批 / 监管决策
- 合同续签或到期
- 并购里程碑（交割日期、监管审批）
- 管理层变动
- 内部交易窗口（锁定期到期）

**行业事件**
- 主要会议（日期、哪些公司出席）
- 行业展会和博览会
- 监管征求意见期或裁决
- 行业数据发布（月度销售、客流等）

**宏观事件**
- 央行会议（FOMC日期）
- 就业报告、CPI、GDP发布
- 其他央行决策（ECB、BOJ等）
- 有市场影响的地缘政治事件

### 步骤 3：日历视图

| 日期 | 事件 | 公司/板块 | 类型 | 影响级别(高/中/低) | 当前仓位 | 备注 |
|------|------|-----------|------|---------------------|----------|------|
| | | | 财报/公司/行业/宏观 | | 多/空/中性 | |

### 步骤 4：每周预览

每周生成前瞻摘要：

**本周重点事件：**
1. [日期]: [公司] Q[X] 财报 — 一致预期 [$X EPS]，我们的预估 [$X]，关键关注：[指标]
2. [日期]: [事件] — 为什么对 [相关股票] 重要
3. [日期]: [宏观数据发布] — 预期和仓位建议

**下周前瞻：**
- 提前提醒即将到来的重要事件

**仓位影响：**
- 可能影响特定持仓的事件
- 是否建议提前布局
- 二元事件前的风险管理

### 步骤 5：输出

格式：简洁的 Markdown 文本，包含日历视图和每周预览。

## 重要说明

- 财报日期可能变动——临近日期时需核实
- 预公告风险：追踪有预公告习惯的公司（正面或负面）
- 会议出席名单很有价值——哪些公司在演讲，哪些明显缺席？
- 有些催化剂是周期性的（月度行业数据）——建立模板后可自动填充
- 按影响级别标注：红色=高影响、黄色=中等、绿色=常规
- 归档过去的催化剂及实际结果——逐步建立模式识别能力
