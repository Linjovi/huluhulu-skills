# DCF模型 -- 正确的实现模式

## 情景区块选择模式

### INDEX公式方法（方法论描述）

情景整合的核心思路是：设定一个情景选择器变量（1=Bear, 2=Base, 3=Bull），通过INDEX函数从对应情景区块中提取假设值。

**实现逻辑：**

1. 分别创建三个假设区块（Bear/Base/Bull），每个区块包含完整的收入增长率、EBIT利润率、终值增长率、WACC等假设，按预测年份横向排列
2. 设定情景选择器单元格，值为1、2或3
3. 整合列使用INDEX公式从选择器指定的情景区块中取值

**INDEX公式示例：**
```
=INDEX(Bear增长率:Base增长率:Bull增长率, 1, 选择器值)
```
其中选择器值 = 1时取Bear, 2时取Base, 3时取Bull

**关键原则：**
- 整合列的每个假设都必须通过INDEX从情景区块取值 -- 不可使用嵌套IF公式
- 模型主预测列（收入、EBIT等）应引用整合列的值，而非直接引用某个情景区块
- 这样用户只需改变选择器值即可切换整个模型情景

**错误示例（避免）：**
```
=IF(选择器=1, Bear增长率, IF(选择器=2, Base增长率, Bull增长率))
```
嵌套IF在情景较多时变得难以维护，且容易出错。

### 情景命名显示

选择器旁边应有一个公式显示当前情景名称：
```
=IF(选择器=1, "Bear", IF(选择器=2, "Base", "Bull"))
```
或使用INDEX从名称数组中取值。

## 收入预测模式

### 基本模式

从最近实际收入开始，每年乘以(1+增长率)：

| 年份 | 收入 | 增长率 |
|------|------|--------|
| 历史最后年 | $100M | 实际值 |
| FY1E | $100M * (1 + g1) | g1 |
| FY2E | FY1收入 * (1 + g2) | g2 |
| FY3E | FY2收入 * (1 + g3) | g3 |

**增长率轨迹应平滑过渡：**
- 不允许增长率在相邻年份出现大幅跳跃（如从20%直接跳到5%）
- 应逐步回落：如20% -> 18% -> 15% -> 12% -> 10%
- 最终年份增长率不应与终值增长率差距过大

### 分业务线模式（适用于多业务板块）

当公司有多个业务线时，应分别预测每条业务线的收入，再加总：

| 业务线 | FY1E | FY2E | ... | 合计占比 |
|--------|------|------|-----|---------|
| 业务A收入 | ... | ... | | X% |
| 业务B收入 | ... | ... | | X% |
| 业务C收入 | ... | ... | | X% |
| 总收入 | A+B+C | A+B+C | | 100% |

每条业务线使用各自的增长率和利润率假设。

## FCF公式模式

### 标准无杠杆FCF构建

每一步必须有明确的计算逻辑：

| 行号 | 项目 | 计算方式 | 说明 |
|------|------|---------|------|
| 1 | EBIT | 毛利润 - 总运营费用 | 或直接引用IS中的EBIT行 |
| 2 | 税费 | EBIT * 税率 | 税率引用WACC表中的税率 |
| 3 | NOPAT | EBIT - 税费 | = 行1 - 行2 |
| 4 | 折旧摊销 | 收入 * D&A占比 | D&A占比引用假设表 |
| 5 | 资本开支 | 收入 * CapEx占比 | CapEx占比引用假设表 |
| 6 | 营运资本变动 | (当年收入 - 上年收入) * NWC占比 | NWC占比引用假设表 |
| 7 | 无杠杆FCF | NOPAT + D&A - CapEx - delta_NWC | = 行3 + 行4 - 行5 - 行6 |

**关键细节：**

1. **折旧摊销**：占收入的比例，通常基于历史趋势。初期可能较高（资本密集型企业），后期趋于稳定。

2. **资本开支**：占收入的比例。注意区分维护性CapEx（维持现有产能）和增长性CapEx（扩张产能）。在成熟期，CapEx占比应下降至接近D&A占比（净资本支出趋于零）。

3. **营运资本变动**：基于收入变动额（delta revenue），而非收入本身。公式：
   ```
   delta_NWC = (当年收入 - 上年收入) * NWC占收入变动额比例
   ```
   典型NWC占比：-2% 至 +2%
   - 正值表示营运资本增加（现金流出）
   - 负值表示营运资本减少（现金流入）

4. **NOPAT而非净利润**：使用NOPAT（扣除利息前的利润 * (1-税率)）而非净利润，因为WACC已经包含了债务成本。如果用净利润再加回利息，会导致债务成本双重计算。

### FCF利润率检验

FCF利润率 = 无杠杆FCF / 收入

| 公司类型 | 典型FCF利润率 |
|---------|-------------|
| 高增长科技 | 5-15%（早期可能为负） |
| 成熟稳定 | 15-25% |
| 周期性 | 波动大，0-20% |

FCF利润率应逐年改善（体现经营杠杆），或在周期性公司中随周期波动。

## 假设表结构

### 每种情景的假设表必须包含以下行

**收入相关假设：**
- 收入增长率（每年一个值）
- 毛利率（每年一个值，体现趋势）

**运营费用假设：**
- 销售与营销占收入比例
- 研发占收入比例
- 一般与行政占收入比例
- （可选）各费用线的改善趋势

**FCF相关假设：**
- 折旧摊销占收入比例
- 资本开支占收入比例
- 营运资本占收入变动额比例
- 税率（通常所有情景使用相同税率）

**估值相关假设：**
- 终值增长率（单一值）
- WACC（单一值）
- 退出倍数（如使用退出倍数法）

### 假设表布局规则

1. 区块标题行必须在最上方，清晰标注情景类型
2. 列标题行显示所有预测年份 -- **不可跳过列标题行**
3. 数据行按逻辑分组（收入假设 -> 运营假设 -> FCF假设 -> 估值假设）
4. 每个假设值必须注明来源或标注为"模型假设"
5. 假设应体现趋势（逐年变化），而非全年使用同一数值

**错误示例（避免）：**
- 所有年份使用同一增长率（没有回落趋势）
- 跳过列标题行（导致模型难以阅读）
- 混合不同情景的假设值

## 敏感性分析实现方法

### 概念与方法论

敏感性分析的目标是展示估值对关键假设变化的敏感程度。每张敏感性表是一个二维网格，行和列分别代表两个关键假设的不同取值，每个单元格是完整DCF重算后的内含股价。

### 三张标准敏感性表

**表1：WACC vs 终值增长率**

展示企业价值对折现率和永续增长假设的敏感度。这是DCF模型中最重要的敏感性表，因为WACC和终值增长率是DCF估值中影响最大的两个参数。

- 行标题：WACC的不同取值（以基准WACC为中心，上下各扩展2步）
- 列标题：终值增长率的不同取值（以基准终值增长率为中心，左右各扩展2步）
- 每个单元格：对应WACC和终值增长率组合下的完整DCF重算结果

**表2：收入增长率 vs EBIT利润率**

展示收入增长和经营杠杆对估值的影响。

- 行标题：收入增长率的不同取值
- 列标题：EBIT利润率的不同取值
- 每个单元格：对应增长率和利润率组合下的完整DCF重算结果

**表3：Beta vs 无风险利率**

展示股权成本各组成部分对估值的影响。

- 行标题：Beta的不同取值
- 列标题：无风险利率的不同取值
- 每个单元格：对应Beta和无风险利率组合下的完整DCF重算结果

### 网格规则

1. **使用奇数行和奇数列**（5x5为标准，7x7用于需要更细粒度的分析）
2. **中心单元格 = 基准情景** -- 轴值设置使中间行和中间列的标题恰好等于模型实际假设
3. **中心单元格的值必须等于模型实际内含股价** -- 这是验证敏感性表正确性的关键检验
4. **所有单元格必须是完整的DCF重算** -- 不使用线性近似或插值，每个单元格需要：重新计算FCF、重新折现、重新计算终值、重新推导股权价值
5. **不使用占位文字** -- 每个单元格都有实际数值
6. **标注中心单元格** -- 在输出中明确标记中心单元格（如用粗体或特殊标记）

### 每个单元格的计算逻辑

对于WACC vs 终值增长率表中的每个单元格：

1. 使用该单元格对应的WACC值重新计算折现因子
2. 使用该单元格对应的终值增长率重新计算终值FCF和终值
3. 重新折现所有FCF和终值
4. 推导企业价值 -> 股权价值 -> 每股价格
5. 返回内含每股价格

对于收入增长率 vs EBIT利润率表中的每个单元格：

1. 使用该单元格对应的收入增长率重新预测收入
2. 使用该单元格对应的EBIT利润率重新计算EBIT和NOPAT
3. 重新构建FCF
4. 使用基准WACC和终值增长率折现
5. 推导内含每股价格

对于Beta vs 无风险利率表中的每个单元格：

1. 使用该单元格对应的Beta和无风险利率重新计算股权成本
2. 重新计算WACC
3. 使用新WACC重新折现所有FCF和终值
4. 推导内含每股价格

### 5x5示例（WACC vs 终值增长率）

假设基准WACC = 9.0%，基准终值增长率 = 3.0%

| | 2.0% | 2.5% | **3.0%** | 3.5% | 4.0% |
|---|---|---|---|---|---|
| 8.0% | $42.5 | $48.2 | $55.7 | $65.4 | $78.2 |
| 8.5% | $39.8 | $44.6 | $51.0 | $58.8 | $68.5 |
| **9.0%** | $37.5 | $41.8 | **$47.2** | $53.5 | $61.2 |
| 9.5% | $35.4 | $39.2 | $44.0 | $49.6 | $56.0 |
| 10.0% | $33.5 | $36.9 | $41.0 | $46.0 | $51.8 |

中心单元格 $47.2 = 模型实际内含股价

**验证方法：**
- 中心单元格值 = 模型在基准假设下的内含股价
- 如果不一致，说明敏感性表的计算逻辑有错误

### 轴值步长选择

- WACC步长：通常0.5%（如8.0%, 8.5%, 9.0%, 9.5%, 10.0%）
- 终值增长率步长：通常0.5%（如2.0%, 2.5%, 3.0%, 3.5%, 4.0%）
- 收入增长率步长：通常1-2个百分点
- EBIT利润率步长：通常1-2个百分点
- Beta步长：通常0.1-0.2
- 无风险利率步长：通常0.5%

### 边界约束

- 终值增长率必须始终 < WACC（否则产生无限价值）
- 如果某个单元格的组合会导致终值增长率 >= WACC，标记为"N/A"或"无限值"
- 所有其他单元格必须返回有效数值
