# DCF模型 -- 常见错误

以下错误在DCF建模中频繁出现，必须避免。

---

## 1. 敏感性表简化

### 错误描述

敏感性表的单元格中只填了占位文字（如"计算中"、"待填"）或使用了线性近似而非完整DCF重算。

### 为什么是错误

敏感性分析的核心价值在于展示估值对假设变化的非线性响应。线性近似无法捕捉DCF模型的凸性特征（WACC降低时估值加速上升），会导致在极端假设组合下产生严重偏差。占位文字则完全使敏感性表失去意义。

### 正确做法

每个单元格必须执行完整DCF重算：重新预测收入 -> 重新计算EBIT -> 重新构建FCF -> 重新折现 -> 重新计算终值 -> 推导内含股价。5x5表共25个单元格，三张表共75个，每个都需要完整计算。

### 验证方法

中心单元格的值必须精确等于模型在基准假设下的内含股价。如果不等，说明计算逻辑有误。

## 2. 缺少假设来源注释

### 错误描述

模型中的硬编码数值（增长率、利润率、WACC参数等）没有标注数据来源，用户无法判断假设的可靠性。

### 为什么是错误

没有来源注释的假设等同于"拍脑袋"。机构级模型的基本要求是每个输入值都可追溯到来源文档或分析。当假设需要更新时，没有注释的模型几乎无法维护。

### 正确做法

每个硬编码值必须注明：
- **来源**：文档名称/用户输入/其他模型引用
- **日期**：数据获取或假设设定的日期
- **参考**：具体位置（如"10-K第42页"、"管理层指引2024Q3"）

输出时以文字标注，如：
```
收入增长率 FY1: 15%
  来源: 管理层指引, 2024Q3财报电话会
  日期: 2024-11-15
```

## 3. 公式行引用错误

### 错误描述

公式引用了错误的行号，导致计算结果不正确。这在模型结构发生变化（插入/删除行）后尤其容易发生。

### 为什么是错误

行引用错误会导致整个模型的结果不正确，而且往往不会产生明显错误信号（如#REF!），因为引用的单元格可能有合法数值，只是引用了错误的行。这是最难发现的错误类型。

### 正确做法

1. **先定义所有行位置，再写公式** -- 确定模型的完整布局后才开始填充计算逻辑
2. **使用一致的命名约定** -- 如"NOPAT行"而非"第45行"，减少混淆
3. **逐步验证** -- 每写完一个区块的公式，立即检查引用是否正确
4. **避免后期插入/删除行** -- 如果必须调整结构，需要重新检查所有下游引用

### 检查方法

对模型中的每个关键计算，手动验证：
- EBIT = 毛利润 - 总运营费用（检查引用的行号是否正确）
- NOPAT = EBIT - 税费（检查EBIT引用）
- 无杠杆FCF = NOPAT + D&A - CapEx - delta_NWC（检查每个加项和减项的引用）

## 4. 运营费用基于毛利润而非收入

### 错误描述

将销售与营销、研发、一般与行政等运营费用计算为毛利润的百分比，而非收入的百分比。

### 为什么是错误

运营费用（S&M、R&D、G&A）是公司的经营成本，应与收入规模挂钩，而非与毛利润挂钩。如果基于毛利润：
- 当毛利率改善时，运营费用的绝对额反而增加（因为毛利润更大），这与经营杠杆的直觉相反
- 费用占比的含义变得模糊 -- 30%的"销售费用占毛利润"在不同毛利率下意味着完全不同的费用水平
- 与行业惯例不一致 -- 投行和 Equity Research 中运营费用总是占收入的百分比

### 正确做法

- 销售与营销 = 收入 * S&M占收入比例
- 研发 = 收入 * R&D占收入比例
- 一般与行政 = 收入 * G&A占收入比例
- 总运营费用 = 收入 * (S&M% + R&D% + G&A%)

### 验证方法

检查每个运营费用线：费用额 / 收入 应得到合理的百分比值。如果费用额 / 毛利润 才得到合理值，说明错误地基于了毛利润。

## 5. 终值增长率 >= WACC

### 错误描述

设置的终值增长率大于或等于WACC，导致终值计算产生无限值或负值。

### 为什么是错误

终值 = 终值FCF / (WACC - 终值增长率)
- 如果终值增长率 = WACC，分母为零，终值为无限
- 如果终值增长率 > WACC，分母为负，终值为负值

这在数学上意味着公司将以超过其资本成本的速率永久增长，暗示公司最终将占据整个经济体，这在现实中不可能。

### 正确做法

- 终值增长率必须严格小于WACC
- 通常终值增长率在2.0-3.5%之间，WACC在7-15%之间，保证足够的安全边际
- 在敏感性表中，任何终值增长率 >= WACC的组合必须标记为"N/A"

### 验证方法

- 检查模型：终值增长率 < WACC
- 检查终值占EV比例：应在50-70%
- 如果终值占EV > 75%，即使终值增长率 < WACC，也应审视终值假设的合理性

## 6. 硬编码利润率和倍数

### 错误描述

直接在公式中写入利润率或倍数的具体数值，而非引用假设单元格。

### 为什么是错误

当用户需要修改假设时，硬编码的数值无法统一更新。例如，如果EBIT利润率硬编码为15%，用户想测试17%的情况，需要找到并修改所有包含15%的公式。这在大型模型中几乎不可能不遗漏。

### 正确做法

所有利润率、增长率、倍数等必须引用假设单元格：
- 假设表中定义所有假设值
- 预测列中的公式引用假设表中的单元格
- 修改假设时，所有引用自动更新

## 7. 净债务处理错误

### 错误描述

净债务计算或应用方向错误，如将净现金从EV中减去（应加上），或将净债务加到EV上（应减去）。

### 为什么是错误

净债务 = 总债务 - 现金及等价物
- 净债务为正（债务 > 现金）：应从EV中减去，得到股权价值
- 净债务为负（现金 > 债务，即净现金）：应加到EV上，增加股权价值

方向错误会导致估值严重偏差。

### 正确做法

股权价值 = 企业价值 - 净债务

当净债务为正：EV - 正数 = 较小股权价值
当净债务为负（净现金）：EV - 负数 = EV + 净现金 = 较大股权价值

### 验证方法

- 如果公司有大量净现金，股权价值必须大于企业价值
- 如果公司有大量净债务，股权价值必须小于企业价值

## 8. 使用基本股数而非稀释股数

### 错误描述

内含每股价格 = 股权价值 / 基本流通股数，未考虑期权、RSU、可转换证券的稀释效应。

### 为什么是错误

忽略稀释效应会高估每股价值。对于期权/RSU较多的公司（如科技公司），稀释可能达到5-15%，对每股估值影响显著。

### 正确做法

使用稀释股数计算：
- 稀释股数 = 基本股数 + 期权稀释股数 + RSU稀释股数 + 可转换证券稀释股数
- Treasury stock method 计算期权稀释：期权稀释股数 = 期权数 - (期权数 * 行权价 / 当前股价)
- 内含每股价格 = 股权价值 / 稀释股数

## 9. 增长率轨迹不平滑

### 错误描述

预测期增长率在相邻年份出现大幅跳跃，如从20%直接跳到8%，没有逐步回落。

### 为什么是错误

大幅跳跃暗示公司经营将发生突变（如突然失去增长动力），这通常不是合理假设。DCF模型的假设应该反映渐进的经营趋势变化。

### 正确做法

增长率应逐步回落，如：
- FY1: 20% -> FY2: 18% -> FY3: 15% -> FY4: 12% -> FY5: 10%
- 最后预测年的增长率不应与终值增长率差距过大（差距在3-5个百分点以内）

## 10. 资本开支不随收入增长

### 错误描述

预测期资本开支保持不变或使用固定的绝对额，而非随收入增长而增长。

### 为什么是错误

收入增长通常需要配套的资本投入（产能扩张、设备更新等）。固定CapEx假设意味着公司在收入大幅增长的同时不需要增加资本投入，这在大多数行业不现实。

### 正确做法

资本开支 = 收入 * CapEx占收入比例
- CapEx占比可以逐年变化（高增长期较高，成熟期回落至接近D&A占比）
- 但CapEx绝对额必须随收入增长而增长
