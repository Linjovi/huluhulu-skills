# DCF 估值模型构建器

## 概述

本skill按照投行标准创建机构级DCF模型，用于股权估值。每次分析输出完整的DCF流程文字报告（包含markdown表格），涵盖历史分析、收入预测、运营费用建模、自由现金流计算、WACC推导、折现与终值、估值汇总和敏感性分析。

## 数据来源

本skill假定**所有输入数据由用户提前准备** -- 用户可通过以下方式提供：
- 用户提供的Excel/CSV文件中的历史财务数据（收入、利润率、资本开支等）
- 其他skill/工具已获取的数据（如可比公司分析中的同行倍数）
- 用户直接输入的关键数据（增长率、利润率、WACC参数）

建模前需与用户确认已有数据：历史财务数据、当前市场数据（股价、流通股数）、债务/现金余额，以及用户希望使用的特定假设。

## 关键约束 -- 必读

### 逐步确认（不可跳过）

- 确认数据输入后 -> 展示原始数据块（收入、利润率、股数、净债务），用户确认后再做预测
- 收入预测完成后 -> 展示预测收入和增长率，确认后再建模利润率
- FCF建模完成后 -> 展示完整FCF时间表，确认逻辑后再计算WACC
- WACC完成后 -> 展示计算和输入，确认后再折现
- 终值 + PV完成后 -> 展示估值桥接（EV -> 股权价值 -> 每股价格），确认后再做敏感性分析
- 每个阶段捕获错误 -- 在敏感性分析建完后才发现利润率假设错误意味着要重建所有下游内容

### 公式优于硬编码（不可协商）

- 所有预测、利润率、折现因子、PV和敏感性都必须是可追溯的逻辑公式或计算 -- 不可是随意填入的数值
- 所有比率、增长率、WACC参数等必须明确标注来源和计算方式
- 如果发现自己在"拍脑袋"填数字 -- 立即停止，回到来源数据

### 输出格式

- 直接以文本输出（markdown表格 + 文字说明）
- 不生成Excel/PPT/Word文件
- 所有数值必须注明单位（百万/每股等）
- 所有百分比必须标注为百分数而非小数

## DCF完整流程（10步）

### 第1步：确认数据输入

建模前，确认用户已提供或可提供：
- **历史财务数据**：收入、利润率、资本开支、折旧摊销（3-5年）
- **市场数据**：当前股价、流通股数、Beta
- **资产负债表数据**：总债务、现金及等价物（用于计算净债务）
- **增长假设**：预测期收入增长率
- **利润率假设**：毛利率、EBIT/EBITDA利润率趋势
- **WACC输入**（或让模型计算）：无风险利率、股权风险溢价、债务成本、税率

缺少任何输入都需先向用户索取，不可自行假设。

### 第2步：历史分析（3-5年）

分析并记录：
- **收入增长趋势**：计算CAGR，识别驱动因素
- **利润率演进**：跟踪毛利率、EBIT利润率、FCF利润率
- **资本密集度**：折旧摊销和资本开支占收入比例
- **营运资本效率**：NWC变动占收入增长比例
- **回报指标**：ROIC、ROE趋势

输出历史指标汇总表：

| 指标 | 数值 |
|------|------|
| 收入 | $X 百万 |
| 收入增长（CAGR） | X% |
| 毛利率 | X% |
| EBIT利润率 | X% |
| 折旧摊销占收入比例 | X% |
| 资本开支占收入比例 | X% |
| FCF利润率 | X% |

### 第3步：收入预测

**方法论：**
1. 从最近实际收入（LTM或最近财年）开始
2. 对每个预测年份应用增长率
3. 同时展示金额和计算出的增长率

**增长率框架：**
- 第1-2年：较高增长，反映近期可见性
- 第3-4年：逐步回落至行业平均水平
- 第5年及以后：接近终值增长率

**公式结构：**
- 收入(第N年) = 收入(第N-1年) * (1 + 增长率)
- 增长率(第N年) = 收入(第N年) / 收入(第N-1年) - 1

**三种情景方案：**

| 情景 | 增长率范围 | 说明 |
|------|-----------|------|
| Bear（悲观） | 8-12% | 保守增长 |
| Base（基准） | 12-16% | 最可能情景 |
| Bull（乐观） | 16-20% | 乐观增长 |

### 第4步：运营费用建模

**固定/变动成本分析：**

运营费用应模拟真实的经营杠杆：
- **销售与营销**：通常占收入15-40%，视商业模式而定
- **研发**：科技公司通常占收入10-30%
- **一般与行政**：通常占收入8-15%，随规模扩大应体现杠杆效应

**关键原则：**
- **所有百分比基于收入，而非毛利润** -- 这是常见错误（详见 [常见错误](references/common-mistakes.md)）
- 模型经营杠杆：费用占比应随收入增长而下降
- EBIT = 毛利润 - 总运营费用

### 第5步：自由现金流计算

**按正确顺序构建FCF：**

| 项目 | 计算方式 |
|------|---------|
| EBIT | 毛利润 - 总运营费用 |
| (-) 税费 | EBIT * 税率 |
| = NOPAT | EBIT - 税费 |
| (+) 折旧摊销 | 非现金费用，占收入比例 |
| (-) 资本开支 | 占收入比例，通常4-8% |
| (-) 营运资本变动 | 收入变动额的比例 |
| = 无杠杆自由现金流 | NOPAT + D&A - CapEx - delta_NWC |

**营运资本建模：**
- 计算为收入变动额的比例（delta revenue）
- 典型范围：-2% 至 +2% 的收入变动额

### 第6步：资本成本（WACC）

**CAPM方法计算股权成本：**

| 参数 | 说明 | 典型值 |
|------|------|--------|
| 无风险利率 | 当前10年期国债收益率 | 3-5% |
| Beta | 用户提供或从历史数据计算 | 0.8-1.5 |
| 股权风险溢价 | 市场标准 | 5.0-6.0% |

股权成本 = 无风险利率 + Beta * 股权风险溢价

**债务成本计算：**

税后债务成本 = 税前债务成本 * (1 - 税率)

**资本结构权重：**

| 项目 | 计算 |
|------|------|
| 股权市场价值 | 当前股价 * 流通股数 |
| 净债务 | 总债务 - 现金及等价物 |
| 企业价值 | 股权市值 + 净债务 |

WACC = (股权成本 * 股权权重) + (税后债务成本 * 债务权重)

**典型WACC范围：**

| 公司类型 | WACC范围 |
|---------|---------|
| 大盘稳定型 | 7-9% |
| 成长型 | 9-12% |
| 高增长/高风险型 | 12-15% |

### 第7步：折现率应用（5-10年预测）

**年中惯例（Mid-Year Convention）：**
- 假设现金流在年中发生
- 折现期间：0.5, 1.5, 2.5, 3.5, 4.5...
- 折现因子 = 1 / (1 + WACC)^期间

**现值计算：**
PV of FCF = 无杠杆FCF * 折现因子

### 第8步：终值计算

**永续增长法（首选）：**

终值FCF = 最终年份FCF * (1 + 终值增长率)
终值 = 终值FCF / (WACC - 终值增长率)

**关键约束：终值增长率 < WACC（否则产生无限价值）**

**终值增长率选择：**

| 程度 | 增长率 | 适用 |
|------|--------|------|
| 保守 | 2.0-2.5% | GDP增长率 |
| 适度 | 2.5-3.5% | 行业增长 |
| 积极 | 3.5-5.0% | 仅适用于市场领导者 |

**退出倍数法（替代方案）：**
终值 = 最终年份EBITDA * 退出倍数

**终值合理性检验：**
- 终值应占企业价值的50-70%
- 如果超过75%，模型可能过度依赖终值假设

### 第9步：企业价值到股权价值桥接

**估值汇总结构：**

| 项目 | 计算 |
|------|------|
| (+) 预测FCF现值之和 | 各年PV FCF相加 |
| (+) 终值现值 | 终值 * 折现因子 |
| = 企业价值 | PV FCF之和 + PV终值 |
| (-) 净债务 | 总债务 - 现金及等价物 |
| = 股权价值 | 企业价值 - 净债务 |
| / 流通股数（稀释后） | 包含期权、RSU、可转换证券 |
| = 内含每股价格 | 股权价值 / 稀释股数 |
| 当前股价 | 市场数据 |
| 内含回报率 | (内含价格 / 当前价格) - 1 |

**关键调整：**
- **净债务 = 总债务 - 现金及等价物**
  - 如果为正：从EV中减去（降低股权价值）
  - 如果为负（净现金）：加到EV上（增加股权价值）
- **使用稀释股数**：包含期权、RSU、可转换证券

### 第10步：敏感性分析

构建**三张敏感性表**，展示估值在不同假设下如何变化：

1. **WACC vs 终值增长率** -- 展示企业价值对折现率和永续增长的敏感度
2. **收入增长率 vs EBIT利润率** -- 展示收入增长和经营杠杆的影响
3. **Beta vs 无风险利率** -- 展示股权成本各组成部分的敏感度

**实现方法（概念描述）：**
- 每张表使用奇数行和奇数列（标准5x5，有时7x7）-- 保证有真实的中心单元格
- 中心单元格 = 基准情景。轴值设置使中间行标题和中间列标题恰好等于模型的实际假设值
- 每个单元格必须是对应假设组合的完整DCF重算结果
- 不使用占位文字，不使用线性近似，不使用需要手动操作的步骤
- 中心单元格必须等于模型的实际内含股价

**5x5网格结构示例（WACC vs 终值增长率）：**

| | 2.0% | 2.5% | 3.0% | 3.5% | 4.0% |
|---|---|---|---|---|---|
| 8.0% | [值] | [值] | [值] | [值] | [值] |
| 8.5% | [值] | [值] | [值] | [值] | [值] |
| 9.0% | [值] | [值] | [中心] | [值] | [值] |
| 9.5% | [值] | [值] | [值] | [值] | [值] |
| 10.0% | [值] | [值] | [值] | [值] | [值] |

中心单元格 = 基准WACC(9.0%)与基准终值增长率(3.0%)的交叉，其值必须等于模型的实际内含股价。

敏感性分析的详细实现方法见 [正确模式](references/correct-patterns.md)。

## 三种情景框架

### Bear（悲观）情景
- 保守收入增长（历史范围低端）
- 利润率压缩或无扩张
- 较高WACC（风险溢价增加）
- 较低终值增长率

### Base（基准）情景
- 一致预期或管理层指引的收入增长
- 适度利润率扩张（基于经营杠杆）
- 当前市场隐含的WACC
- GDP水平的终值增长率（2.5-3.0%）

### Bull（乐观）情景
- 乐观收入增长（预测高端）
- 显著利润率扩张
- 较低WACC（降低风险溢价）
- 较高终值增长率（3.5-5.0%）

**情景区块选择方法：**

使用INDEX公式方法进行情景整合：设定一个情景选择器（1=Bear, 2=Base, 3=Bull），通过INDEX函数从对应情景区块中提取假设值，整合到模型的主预测列中。

详细方法见 [正确模式 - 情景区块选择](references/correct-patterns.md)。

## 常见变体

不同公司类型需要调整DCF模型的核心参数：

### 高增长科技公司
- 预测期延长至7-10年（增长周期更长）
- 收入增长率起始较高（15-40%），逐步回落
- 利润率从低水平逐步改善（初始可能为负EBIT）
- 终值增长率偏低（2.0-2.5%），因为高增长最终会放缓
- WACC偏高（10-15%），反映更高风险
- 需要更详细地建模各运营费用线（S&M、R&D、G&A分别预测）

### 成熟稳定型公司
- 预测期5年即可
- 收入增长率接近GDP水平（3-5%）
- 利润率稳定或小幅改善
- 终值增长率与GDP同步（2.5-3.0%）
- WACC较低（7-9%），反映稳定性和较低风险
- FCF利润率较高（15-25%）
- 营运资本变动可能更显著（稳定业务有成熟的WC周期）

### 周期性公司（能源、材料、工业）
- 预测期必须覆盖完整周期（至少7-10年）
- 收入增长率波动大 -- 必须建模周期性起伏，不可简单线性增长
- 利润率在周期高峰和低谷差异显著
- 使用退出倍数法作为终值的交叉验证（周期性公司的永续增长假设容易失真）
- WACC需考虑周期风险溢价
- 敏感性分析范围需更宽（WACC和增长率的极端值组合）

### 多业务板块公司
- 必须分板块建模，每个板块独立预测收入和利润率
- 每个板块使用不同的增长率、利润率假设和终值增长率
- 加总各板块得到整体公司预测
- 各板块可能需要不同的WACC（如果风险特征差异大）或使用公司统一WACC
- 估值汇总时需考虑公司层面的协同/摩擦效应

## 质量检查清单

交付DCF模型前确认：

**必要项：**
- 所有数值注明来源和计算方式
- 三种情景假设完整且合理
- FCF按正确顺序构建（EBIT -> 税 -> NOPAT -> +D&A -> -CapEx -> -delta_NWC）
- WACC各组成部分有来源
- 终值占EV的50-70%（否则说明理由）
- 终值增长率 < WACC
- 税率在合理范围（21-28%或用户指定）
- 净债务正确处理（正为减，负为加）
- 使用稀释股数

**验证项：**
- 运营费用基于收入（而非毛利润）
- 终值增长率 < WACC
- 中心单元格值 = 模型实际内含股价
- 各情景假设逻辑自洽
- 所有增长率、利润率有逐年变化轨迹（不可跳跃）

**与现有市场数据交叉验证：**
- 内含股价与当前股价对比
- 关键倍数（EV/EBITDA、P/E）与可比公司对比
- WACC与行业同行对比
