# 投资论点追踪器

创建和维护投资论点，用于持仓管理和关注列表追踪。当需要用新信息更新论点、审视持仓逻辑、或检查论点是否仍然成立时使用。

## 工作流程

### 步骤 1：定义或加载论点

如果是新建论点，需要用户提供以下信息：

- **公司**：名称和代码
- **方向**：做多 / 做空
- **核心论点**：1-2句话概括核心观点（例如："做多 ACME — 定价权+运营杠杆带来利润率扩张，随着业务组合向软件倾斜"）
- **关键支柱**：3-5个支撑论据
- **主要风险**：3-5个可能推翻论点的风险
- **催化剂**：即将发生、可能证明/推翻论点的事件（财报、产品发布、监管决策等）
- **目标价/估值**：论点兑现后的合理价值
- **止损触发**：什么情况下应该退出

如果是更新已有论点，询问用户提供新的数据点或变化。

### 步骤 2：更新日志

对每个新数据点或变化，记录以下内容：

- **日期**：事件发生时间
- **数据点**：发生了什么变化（财报超预期、管理层变动、竞争对手动作等）
- **论点影响**：这个变化是加强、削弱还是中性化了某个支柱？
- **操作建议**：不变 / 加仓 / 减仓 / 退出
- **信心更新**：高 / 中 / 低

### 步骤 3：论点记分卡

维护一张动态记分卡：

| 支柱 | 原始预期 | 当前状态 | 趋势 |
|------|----------|----------|------|
| 收入增长 >20% | 预期达标 | Q3 为 22% | 稳定 |
| 利润率扩张 | 预期扩张 | 利润率同比持平 | 令人担忧 |
| 新产品发布 | 待发布 | 推迟至 Q2 | 关注 |

### 步骤 4：催化剂日历

追踪即将到来的催化剂：

| 日期 | 事件 | 预期影响 | 备注 |
|------|------|----------|------|
| | | | |

### 步骤 5：输出

论点摘要，适用于：
- 晨会讨论
- 组合回顾
- 风控委员会汇报

格式：简洁的 Markdown 文本，包含记分卡、近期更新和当前信心水平。

## 重要说明

- 论点必须是可证伪的——如果没有任何情况能推翻它，那它就不是论点
- 对否定证据的追踪要和对肯定证据一样严格
- 即使没有重大变化，也至少每季度回顾一次论点
- 如果用户管理多个持仓，可以提议做一次全面的组合论点回顾
- 论点数据应以结构化格式存储，便于跨会话引用
