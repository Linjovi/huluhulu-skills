# A股财务分析评分框架

## 概述

本skill以专业A股量化研究员视角，通过八步多维度评分体系，对A股公司进行系统性财务分析与学习。核心目标：**帮助用户建立结构化的财务分析思维，学习如何从多维度评估上市公司质量**。分析范围仅限A股主板/中小板，排除创业板（300开头）和科创板（688开头）。

> **⚠️ 免责声明**
> 本skill生成的所有分析结果、评分排名和综合评分档位**仅用于学习分析目的，不构成任何投资建议或交易指令**。评分模型基于历史数据和当前可获取信息，无法预测未来市场走势。用户应结合自身判断做出独立决策，并对自己的行为承担全部责任。skill输出中的任何标的分析均不构成买入、卖出或持有的建议。

每次分析输出完整的筛选与评分流程文字报告（Markdown表格 + 文字说明），最终输出Top20分析结果及综合评分档位。

## 数据来源

本skill假定**所有输入数据由用户提前准备** -- 用户可通过以下方式提供：
- 用户提供的Excel/CSV文件中的财务数据（ROE、扣非净利润、营业收入、经营现金流等）
- 其他skill/工具已获取的数据（如资金流向、北向持股、机构调研次数等）
- 用户直接输入的关键数据（行业分类、股东户数、换手率等）

筛选前需与用户确认已有数据：基础财务指标、资金面数据、筹码面数据、技术面数据及行业归属。数据不完整时，要求用户补充后再推进。

## 关键约束 -- 必读

### 筛选范围（不可协商）

- **仅A股主板/中小板**
- **排除创业板**：股票代码以300开头
- **排除科创板**：股票代码以688开头

### 逐步确认（不可跳过）

- 基础过滤完成后 -> 展示通过/淘汰清单及淘汰原因，用户确认后再进入评分
- Step 1-2评分完成后 -> 展示基本面得分，确认后再进入资金面评分
- Step 3-4评分完成后 -> 展示资金面+筹码面得分，确认后再进入行业评分
- Step 5-7评分完成后 -> 展示完整评分表，确认后再输出最终推荐
- **不可一口气从头到尾跑完再呈现**——每个阶段确认，及早发现数据错误

### 评分透明（不可协商）

- 所有评分必须标注对应原始数据值和得分依据
- 不允许出现"凭感觉给分"——每个分数都必须可追溯到具体数据
- 如果某项数据缺失，该项得0分并明确标注"数据缺失"

### 输出格式

- 直接以文本输出（Markdown表格 + 文字说明）
- 不生成Excel/PPT/Word文件
- 所有股票代码必须带交易代码（如：600519.SH、000858.SZ）
- 所有分析结果必须明确标注"仅用于学习分析"

## 完整筛选流程（8步）

### Step 1：基础过滤（不满足直接淘汰）

以下条件为**硬性门槛**，任一不满足即淘汰，不进入后续评分：

| 过滤条件 | 阈值要求 | 说明 |
|----------|----------|------|
| ST状态 | 非ST | 排除所有ST、*ST股票 |
| 上市时间 | > 2年 | 排除次新股，确保有足够历史数据 |
| 流通市值 | 50亿 ~ 2000亿 | 排除微型股和超大盘股 |
| ROE(TTM) | > 8% | 确保基本盈利能力 |
| 经营现金流 | 为正 | 排除现金流恶化的公司 |
| 最近一年 | 无亏损 | 排除最近年度亏损的公司 |

**输出格式：**

| 股票名称 | 股票代码 | ST状态 | 上市时间 | 流通市值(亿) | ROE(TTM) | 经营现金流 | 最近一年盈亏 | 过滤结果 | 淘汰原因 |
|----------|----------|--------|----------|-------------|----------|-----------|------------|----------|----------|
| | | | | | | | | 通过/淘汰 | |

通过基础过滤的股票进入Step 2-8逐项评分。

### Step 5：行业景气度评分（15分）

行业景气度评分**不预设固定分值**，而是由agent根据当前市场环境动态评估。行业景气度会随宏观周期、政策导向、技术突破和供需格局变化而变化，因此评分必须反映分析时点的真实市场状态。

**评分框架（1-15分）：**

| 景气度评级 | 得分区间 | 判定依据 |
|-----------|----------|--------|
| 高景气上行 | 13-15分 | 行业处于强景气周期，政策/技术/需求三重驱动，业绩兑现确定性高 |
| 中高景气 | 10-12分 | 行业景气向上但存在分歧，部分子赛道已兑现部分预期 |
| 中性景气 | 7-9分 | 行业平稳运行，无明显向上或向下拐点 |
| 低景气 | 4-6分 | 行业景气下行或筑底，但存在边际改善可能 |
| 景气下行 | 1-3分 | 行业处于下行周期，供需恶化，短期难见拐点 |

**评估维度：**
agent在评估行业景气度时，应综合考量以下因素：

1. **政策导向**：是否有国家级产业政策支持（如补贴、税收优惠、专项规划）
2. **需求景气**：下游需求是否处于扩张周期（订单、出货量、价格趋势）
3. **技术催化**：是否存在重大技术突破或迭代驱动行业升级
4. **供给格局**：行业产能利用率、竞争格局是否改善
5. **资本开支**：行业资本开支增速是否指示未来景气方向
6. **价格信号**：核心产品/服务价格趋势（涨价=景气上行信号）

**说明：**
- 若标的跨多个行业，取主要收入来源行业进行评分
- 需明确标注行业归类依据和景气度评估理由
- 评分必须引用具体的市场信号或数据支撑，不可凭空给分
- 若用户对行业景气度有特定观点，优先采纳用户判断

**行业景气度评分输出格式：**

| 股票名称 | 股票代码 | 归属行业 | 行业归类依据 | 景气度得分 |
|----------|----------|----------|-------------|-----------|
| | | | | /15 |

### Step 6：预期差评分（20分）

分析市场关注度与基本面变化之间的差异，重点考察以下四个维度：

| 预期差维度 | 说明 |
|-----------|------|
| 机构关注度提升 | 近期机构覆盖明显增加 |
| 市场热度不高 | 散户关注度较低 |
| 最近半年涨幅 < 30% | 价格变化幅度较小 |
| 业绩出现拐点 | 基本面出现向上拐点信号 |

**评分规则：**
- 满足4项：20分
- 满足3项：15分
- 满足2项：10分
- 满足1项：5分
- 满足0项：0分

**预期差评分输出格式：**

| 股票名称 | 股票代码 | 机构关注度 | 市场热度 | 半年涨幅 | 业绩拐点 | 满足项数 | 预期差得分 |
|----------|----------|-----------|----------|----------|----------|----------|-----------|
| | | 提升/未提升 | 不高/较高 | X% | 有/无 | /4 | /20 |

### Step 7：技术面评分（20分）

**核心原则：技术面评分仅用于分析参考，不代表交易建议。**

每项5分，满足即得分：

| 技术条件 | 得分 |
|----------|------|
| MA20 > MA60 | 5分 |
| MA60走平向上 | 5分 |
| 距52周高点15% - 35% | 5分 |
| 最近20日放量 | 5分 |

**说明：**
- "距52周高点15%-35%"意味着当前价格处于52周高点的65%-85%区间，既非高位也非深跌
- "最近20日放量"指近20日成交量均量高于前期均量
- 技术面评分仅反映技术指标状态，需结合其他维度综合分析

**技术面评分输出格式：**

| 股票名称 | 股票代码 | MA20 vs MA60 | MA60趋势 | 距52周高点 | 20日放量 | 技术面总分 |
|----------|----------|-------------|----------|-----------|----------|-----------|
| | | ✓/✗ (5/0) | 走平向上/否 (5/0) | X% ✓/✗ (5/0) | 是/否 (5/0) | /20 |

### Step 8：最终输出

#### 8.1 计算总分

**总分 = 基本面得分 + 资金面得分 + 筹码得分 + 行业景气度得分 + 预期差得分 + 技术面得分**

理论满分 = 35 + 25 + 20 + 15 + 20 + 20 = **135分**

#### 8.2 综合评分档位（仅用于学习分析）

| 评分档位 | 总分要求 | 说明 |
|----------|----------|------|
| 一档 | > 85分 | 各维度表现突出，综合质量较高 |
| 二档 | 75 - 85分 | 多数维度表现良好 |
| 三档 | 65 - 75分 | 部分维度有亮点，整体表现中等 |
| 四档 | < 65分 | 各维度表现一般，需进一步研究 |
