# 公式参考、统计计算方法与示例模板

## 一、核心计算公式

### 利润率计算

| 指标 | 计算公式 | 说明 |
|------|----------|------|
| 毛利率 | 毛利润 / 收入 | 基础盈利能力，扣除营业成本后 |
| EBITDA利润率 | EBITDA / 收入 | 运营效率，扣除利息、税、折摊前 |
| 营业利润率 | 营业利润 / 收入 | 含折摊的运营效率 |
| 净利率 | 净利润 / 收入 | 最终盈利能力 |
| FCF利润率 | 自由现金流 / 收入 | 现金生成效率 |

### 估值倍数计算

| 指标 | 计算公式 | 说明 |
|------|----------|------|
| 企业价值(EV) | 市值 + 净债务（总债务 - 现金） | 全企业价值视角 |
| EV/收入 | 企业价值 / 收入 | 每美元销售额的市场定价 |
| EV/EBITDA | 企业价值 / EBITDA | 每美元盈利的市场定价 |
| P/E | 股价 / 每股收益（或 市值 / 净利润） | 价格相对净盈利 |
| PEG | P/E / 收入增速(%) | 增长调整后的估值 |
| P/B | 市值 / 账面权益 | 市值vs会计价值 |
| FCF收益率 | 自由现金流 / 市值 | 现金回报率 |
| 股息率 | 年度股息 / 股价 | 股息回报率 |

### 增速计算

| 指标 | 计算公式 | 说明 |
|------|----------|------|
| 同比增速(YoY) | (本期 - 上期) / 上期 | 单期同比变化 |
| CAGR | (终值/初值)^(1/年数) - 1 | 多年复合年增速 |
| 季度环比增速(QoQ) | (本季 - 上季) / 上季 | 季度间变化 |

### 特殊指标

| 指标 | 计算公式 | 适用行业 |
|------|----------|----------|
| Rule of 40 | 收入增速(%) + FCF利润率(%)（或EBITDA利润率%） | SaaS/软件 |
| FCF转化率 | 自由现金流 / EBITDA | 盈利质量分析 |
| 效率比率 | 非利息支出 / 总收入 | 银行/金融 |
| 资产周转率 | 收入 / 总资产 | 制造/工业 |
| 净美元留存率(NDR) | (期初ARR + 扩展 - 流失 - 收缩) / 期初ARR | SaaS |

## 二、统计计算方法

### 五级统计量

对每个可比指标列，计算以下5个统计量：

| 统计量 | 计算方法 | 作用 |
|--------|----------|------|
| 最大值 | 取该列所有公司数值中的最大值 | 识别极端高值 |
| 75分位数 | 将数值从小到大排列，取第75%位置的值 | 高端基准 |
| 中位数 | 将数值从小到大排列，取中间位置的值 | **最核心的基准** |
| 25分位数 | 将数值从小到大排列，取第25%位置的值 | 低端基准 |
| 最小值 | 取该列所有公司数值中的最小值 | 识别极端低值 |

### 中位数的计算步骤

1. 将该列所有公司的数值从小到大排列
2. 如果有N个数值：
   - N为奇数：中间位置的值即为中位数（如7个值，第4个为中位数）
   - N为偶数：中间两个值的平均（如6个值，第3和第4的平均为中位数）

### 四分位数的计算步骤

1. 将数值从小到大排列
2. 25分位数（Q1）：约25%的数据低于此值
3. 75分位数（Q3）：约75%的数据低于此值
4. 计算方法：中位数将数据分为上下两组，分别取各组的中位数即得Q1和Q3

### 为什么用中位数而非均值？

| 原因 | 说明 |
|------|------|
| 抗极端值 | 均值受单个极端值影响，中位数不受 |
| 更具代表性 | 可比组通常样本小(3-10家)，极端值影响大 |
| 行业惯例 | 投行与PE普遍使用中位数作为基准 |
| 分位数更丰富 | Q1/Q3与中位数组合，提供完整的分布概览 |

### 均值与中位数的对比示例

```
5家公司的EV/EBITDA: 8x, 9x, 10x, 11x, 45x

均值 = (8+9+10+11+45)/5 = 16.6x  (被45x拉高)
中位数 = 10x                    (真实反映典型水平)

结论：中位数10x更代表"正常"估值水平
```

## 三、需要统计与不需要统计的列

### 需要统计的列

这些指标跨公司可比，统计有意义：

- 收入增速%
- 毛利率%
- EBITDA利润率%
- FCF利润率%
- 净利率%
- EPS
- EV/收入
- EV/EBITDA
- P/E
- PEG
- P/B
- FCF收益率%
- 股息率%
- Beta
- Rule of 40
- 资产周转率

### 不需要统计的列

这些指标是绝对规模，不同体量公司间不可比：

- 收入（绝对值）
- 毛利润（绝对值）
- EBITDA（绝对值）
- 净利润（绝对值）
- 市值
- 企业价值

## 四、合理性检查参考范围

### 利润率层级（必须满足）

```
毛利率 > EBITDA利润率 > 营业利润率 > 净利率

原因：每一层扣除更多成本项
违反此规则 = 数据错误或定义不一致
```

### 估值倍数参考范围

| 倍数 | 典型范围 | 备注 |
|------|----------|------|
| EV/收入 | 0.5 - 20x | 行业差异大，SaaS可高达20x+ |
| EV/EBITDA | 8 - 25x | 各行业相对一致 |
| P/E | 10 - 50x | 取决于增速与稳定性 |
| PEG | 0.5 - 3.0 | <1可能低估，>2可能高估 |
| P/B | 0.5 - 5.0 | 资产密集型偏低，轻资产偏高 |

### 增速-倍数关系

```
一般规律：增速越高 -> 倍数越高
违背此规律的可能原因：
  - 高增速但盈利质量差（FCF转化率低）
  - 市场对增速可持续性存疑
  - 行业结构性风险（监管、竞争）
```

## 六、常见数据陷阱

### EBITDA定义差异

不同公司对EBITDA的定义可能不同：
- 方案A：毛利润 + D&A
- 方案B：营业利润 + D&A
- 方案C：净利润 + 利息 + 税 + D&A

**处理方法：** 统一采用一种定义，并在注释中声明。推荐方案B（营业利润 + D&A），因毛利润法可能遗漏营业费用。

### 时间段不一致

- 财年截止日不同（如6月vs12月）
- 混用LTM与季度数据

**处理方法：** 尽量统一为LTM或同一季度；无法统一时，在注释中声明差异。

### 一次性项目

- 赸销收入、重组费用、资产减值等一次性项目
- 可能扭曲"正常"盈利能力

**处理方法：** 排除一次性项目以计算标准化EBITDA，在注释中列出调整项。

### 资本结构差异

- 有的公司大量债务，有的几乎无债
- EV/EBITDA vs P/E的选择受此影响

**处理方法：** 高杠杆公司优先用EV倍数（含债务视角）；低杠杆公司P/E也适用。
