# 指标选择决策框架、行业特定指标与5-10规则

## 一、指标选择决策框架

### 第一步：明确核心问题

**"哪家公司被低估？"**
- 聚焦：EV/收入、EV/EBITDA、P/E、市值
- 跳过：运营细节、增速指标

**"哪家公司最高效？"**
- 聚焦：毛利率、EBITDA利润率、FCF利润率、资产周转率
- 跳过：规模指标、绝对金额

**"哪家公司增长最快？"**
- 聚焦：收入增速%、EBITDA CAGR、用户/客户增速
- 跳过：利润率指标、杠杆比率

**"哪家现金生成最强？"**
- 聚焦：FCF、FCF利润率、FCF转化率、资本支出强度
- 跳过：EBITDA、P/E比率

### 第二步：根据行业特征细化

每个行业有"必选指标"和"应跳指标"。详见下方行业特定指标部分。

### 第三步：应用5-10规则控制总量

详见下方5-10规则部分。

## 二、行业特定指标选择

### 软件/SaaS

| 类别 | 指标 | 说明 |
|------|------|------|
| 必选 | 收入增速 | 核心增长信号 |
| 必选 | 毛利率 | SaaS毛利率通常70-85% |
| 必选 | Rule of 40 | 增速% + 利润率%，行业金标准 |
| 可选 | ARR | 年化经常性收入 |
| 可选 | 净美元留存率(NDR) | 客户扩展/留存指标 |
| 可选 | CAC回收期 | 客户获取成本回收周期 |
| 跳过 | 资产周转率 | SaaS资产结构不同 |
| 跳过 | 库存指标 | 无库存业务 |

### 制造业/工业

| 类别 | 指标 | 说明 |
|------|------|------|
| 必选 | EBITDA利润率 | 运营效率核心 |
| 必选 | 资产周转率 | 重资产行业必备 |
| 必选 | 资本支出/收入 | 再投资强度 |
| 可选 | ROA | 资产回报率 |
| 可选 | 库存周转率 | 供应链效率 |
| 可选 | 订单积压(Backlog) | 未来收入可见性 |
| 跳过 | Rule of 40 | 不适用 |
| 跳过 | SaaS指标 | 不适用 |

### 金融服务业

| 类别 | 指标 | 说明 |
|------|------|------|
| 必选 | ROE | 股东回报核心 |
| 必选 | ROA | 资产回报 |
| 必选 | 效率比率 | 成本/收入，运营效率 |
| 必选 | P/E | 银行估值最常用 |
| 可选 | 净息差(NIM) | 利差收入指标 |
| 可选 | 贷款损失准备 | 信用风险指标 |
| 跳过 | 毛利率 | 银行无毛利率概念 |
| 跳过 | EBITDA | 对银行无意义 |

### 零售/电商

| 类别 | 指标 | 说明 |
|------|------|------|
| 必选 | 收入增速 | 增长信号 |
| 必选 | 毛利率 | 加价能力 |
| 必选 | 库存周转率 | 供应链效率 |

| 可选 | 客户获取成本(CAC) | 营销效率 |
| 跳过 | 重R&D或资本支出指标 | 一般不适用 |

### 互联网/媒体

| 类别 | 指标 | 说明 |
|------|------|------|

| 必选 | 毛利率 | 内容/平台成本结构 |

| 可选 | DAU/MAU | 用户活跃度 |

## 三、5-10规则

### 核心定义

- **5个经营指标**：收入、增速、2-3个利润率/效率指标
- **5个估值指标**：市值、EV、3个倍数
- **合计10列**：足够讲述故事，不至于迷失主线

### 为什么是5-10？

| 列数 | 效果 |
|------|------|
| < 5 | 信息不足，无法得出结论 |
| 5-10 | 精准聚焦，故事清晰 |
| 10-15 | 开始出现噪音，需要仔细筛选 |
| > 15 | 大量噪音，主线模糊 |

### 执行要点

1. **先列满所有可能指标**，然后逐一问"这个指标对回答核心问题有直接帮助吗？"
2. **如果回答为否，果断删除**。宁缺毋滥。
3. **行业必选指标优先纳入**，再根据核心问题补充1-2个特定指标。
4. **最终列数控制在10以内**。超过15时，几乎肯定包含了噪音。

### 常见的过度指标及如何精简

| 过度指标 | 精简方法 |
|----------|----------|
| 同时展示收入、净利润、EBITDA、营业利润 | 选1个规模指标 + 1个盈利指标 |
| 同时展示EV/收入、EV/EBITDA、P/E、P/B、EV/FCF | 选2-3个最相关的倍数 |
| 季度+年度+LTM三套增速 | 根据场景选1套 |
| 同时展示ROE、ROA、ROIC、ROI | 选1个回报指标 |

## 四、指标组合模式

### 通用估值组合（适用于大多数场景）

| 经营指标 | 估值指标 |
|----------|----------|
| 收入 | 市值 |
| 收入增速 | 企业价值 |
| 毛利率 | EV/收入 |
| EBITDA | EV/EBITDA |
| EBITDA利润率 | P/E |

### 高增长公司组合

| 经营指标 | 估值指标 |
|----------|----------|
| 收入 | 市值 |
| 收入增速 | 企业价值 |
| 毛利率 | EV/收入 |
| FCF | PEG比率 |
| Rule of 40 | EV/收入增速 |

### 成熟现金生成组合

| 经营指标 | 估值指标 |
|----------|----------|
| 收入 | 市值 |
| EBITDA利润率 | 企业价值 |
| FCF | FCF收益率 |
| FCF转化率 | P/E |
| 资本支出/收入 | 股息率 |

## 五、决策流程图

```
开始 -> 确定核心问题
       |
       v
  选择行业必选指标 (见行业特定指标表)
       |
       v
  根据核心问题补充1-2个特定指标
       |
       v
  计算总列数 -> 若 > 10, 删除最不相关指标
       |
       v
  确认最终列组合 -> 5个经营 + 5个估值
       |
       v
  开始构建分析
```
