# 可比公司分析

## 数据来源

本技能假定**所有输入数据由用户提前准备**。数据来源包括：
- 用户提供的财务指标数据（收入、EBITDA、利润率、市值等）
- 通过其他技能/工具已获取的数据
- 用户直接提供的关键数字

开始前，确认用户已具备的数据：可比公司名称、财务指标、估值数据及具体时间段。数据不完整时，要求用户补充后再推进。

## 概览

本技能构建机构级可比公司分析，结合经营指标、估值倍数与统计基准，以结构化文本输出，辅助投资决策中的对标分析。

**开始前先问自己：**
1. **"你有偏好的呈现格式吗，还是我来适配？"**
2. **"受众是谁？"**（投委会、董事会演示、快速参考、详细备忘录）
3. **"核心问题是什么？"**（估值、增长分析、竞争定位、运营效率）
4. **"场景是什么？"**（并购评估、投资决策、行业基准、绩效复盘）

**根据具体情况调整：**
- **行业背景**：大型科技巨头与新兴SaaS初创公司需要不同指标
- **行业特定需求**：尽早加入相关指标（如科技行业加入云ARR、企业客户数、开发者生态）
- **公司熟悉度**：知名公司可减少背景介绍，更多聚焦增量分析
- **决策类型**：并购评估与持续组合监控的侧重点不同

**核心原则：** 采用模板的结构化思维与统计严谨性，但根据具体场景灵活执行。目标是机构级质量的分析，而非机构级外观的模板。

用户的示例和明确偏好始终优先于默认设置。

## 核心哲学

**"先搭正确的结构，再让数据讲述故事。"**

从需要战略性思考的表头开始，输入干净的数据，构建透明的计算逻辑，让统计自然呈现。一份好的可比公司分析应该让没参与构建的人也能立刻读懂。

---

## 关键原则：逐步验证

**逐步与用户确认：**
- 设定结构后 -> 向用户展示表头布局，确认后再填数据
- 输入原始数据后 -> 向用户展示数据区块，确认来源与时间段后再构建计算
- 构建经营指标后 -> 展示计算出的利润率，与用户一起做合理性检查后再进入估值
- 构建估值倍数后 -> 展示倍数，确认合理性后再加入统计
- **不要一口气从头到尾建完再呈现**——在每个环节确认，及早发现错误

**所有衍生值（利润率、倍数、统计量）必须通过计算公式得出，而非粘贴预算结果。** 只有原始输入数据（收入、EBITDA、股价等）是硬编码的，每个硬编码值都应标注数据来源。

## 第1步：输出结构与标题

### 标题区块

```
[分析标题] - 可比公司分析
[公司名称与代码列表] | [公司1 (代码1)] | [公司2 (代码2)] | [公司3 (代码3)]
截至 [时间段] | 所有金额单位为 [百万/十亿美元]（每股金额与比率除外）
```

**为什么重要：** 立即建立上下文。任何人看到这份分析都能知道：看的是什么、何时创建、如何解读数字。

### 格式规范

- **百分比**：保留1位小数（12.3%）
- **倍数**：保留1位小数（13.5x）
- **金额**：无小数，千位分隔符（69,632）
- **利润率**：以百分比显示，保留1位小数（68.7%）
- **对齐**：所有指标列居中对齐

## 第2步：经营指标与财务数据

### 核心列（从这里开始）

| 列名 | 说明 |
|------|------|
| 公司 | 名称，格式统一 |
| 收入 | 规模指标（可按LTM、季度或年度，取决于场景） |
| 收入增速 | 同比百分比变化 |
| 毛利润 | 收入减去营业成本 |
| 毛利率 | 毛利润/收入（基础盈利能力） |
| EBITDA | 息税折摊前利润 |
| EBITDA利润率 | EBITDA/收入（运营效率） |

### 可选扩展（根据行业/目的选择）

| 指标 | 适用场景 |
|------|----------|
| 季度 vs LTM | 季节性显著时同时展示 |
| 自由现金流(FCF) | 资本密集或SaaS行业 |
| FCF利润率 | FCF/收入（现金生成效率） |
| 净利润 | 成熟盈利公司 |
| 营业利润 | D&A差异较大的业务 |
| 资本支出指标 | 资产密集型行业 |
| Rule of 40 | SaaS专用（增速% + 利润率%） |
| FCF转化率 | 盈利质量分析（进阶） |

### 计算方法

```
毛利率 = 毛利润 / 收入
EBITDA利润率 = EBITDA / 收入
FCF利润率 = 自由现金流 / 收入
净利率 = 净利润 / 收入
Rule of 40 = 收入增速(%) + FCF利润率(%)
```

**黄金法则：** 每个比率都应该是 [某指标] / [收入] 或 [某指标] / [本表中的另一指标]。保持简洁。

### 统计区块

在所有可比指标下方加入统计行：

```
[空一行作为视觉分隔]

最大值：该列所有公司数值的最大值
75分位数：该列所有公司数值的第75百分位
中位数：该列所有公司数值的中位数
25分位数：该列所有公司数值的第25百分位
最小值：该列所有公司数值的最小值
```

**需要统计的列（可比指标）：**
- 收入增速%、毛利率%、EBITDA利润率%、EPS
- EV/收入、EV/EBITDA、P/E、股息率%、Beta

**不需要统计的列（规模指标）：**
- 收入、EBITDA、净利润（绝对规模因公司体量不同而不可比）
- 市值、企业价值（不同体量公司间不可比）

> 不需要添加"行业统计"或"估值统计"标题行。仅用空行分隔即可。

## 第3步：估值倍数与投资指标

### 核心估值列（从这里开始）

| 列名 | 说明 |
|------|------|
| 公司 | 与经营指标部分顺序一致 |
| 市值 | 当前市场估值 |
| 企业价值(EV) | 市值 +/- 净债务/现金 |
| EV/收入 | 市场对每美元销售额的定价 |
| EV/EBITDA | 市场对每美元盈利的定价 |
| P/E比率 | 价格相对净利润 |

### 可选估值指标（根据场景选择）

| 指标 | 适用场景 |
|------|----------|
| FCF收益率 | FCF/市值（聚焦现金的分析） |
| PEG比率 | P/E/增速（成长型公司） |
| 市净率(P/B) | 市值vs账面价值（资产密集型业务） |
| ROE/ROA | 回报指标（盈利能力对比） |
| 收入/EBITDA CAGR | 历史复合增速（趋势分析） |
| 资产周转率 | 收入/资产（运营效率） |
| 负债/权益比率 | 杠杆（资本结构分析） |

### 交叉引用规则

**关键：** 估值倍数必须引用经营指标部分的数据，同一原始数据不得重复输入。

### 统计区块

同经营指标部分：最大值、75分位数、中位数、25分位数、最小值。用空行分隔公司与统计行，不加标题行。

## 第4步：注释与方法论文档

### 必备内容

**数据来源与质量：**
- 数据从何而来？（用户提供、SEC文件、分析师报告）
- 涵盖什么时间段？（如2024年Q4、审计数据）
- 如何验证？（与10-K/10-Q交叉核对）
- 记录任何数据缺口或估算值

**关键定义：**
- EBITDA计算方法（毛利润+D&A，或营业利润+D&A）
- 自由现金流公式（经营现金流 - 资本支出）
- 特殊指标解释（Rule of 40、FCF转化率）
- 时间段定义（LTM、CAGR计算期间）

**估值方法论：**
- 企业价值如何计算？（市值+净债务）
- 使用了什么增速？（历史CAGR、前瞻估算）
- 是否做了调整？（排除一次性项目、标准化利润率）

## 第6步：最佳实践与质量检查

> 公式参考、计算方法与示例模板，参见 [references/formulas-and-stats.md](references/formulas-and-stats.md)

### 开始前

1. **定义可比组** —— 公司必须真正可比（相似商业模式、规模、地域）
2. **选择正确时间段** —— LTM平滑季节性；季度展示趋势
3. **预先统一单位** —— 百万vs十亿的决定影响全局
4. **映射数据来源** —— 知道每个数字从何而来

### 构建过程中

1. **先输入所有原始数据** —— 完成输入后再构建计算
2. **标注所有硬编码输入的数据来源**
3. **逐行构建计算逻辑** —— 每个计算验证后再推进
4. **格式统一** —— 百分比显示为百分比而非小数
5. **标记异常值** —— 自动识别偏离中位数的公司

### 合理性检查

- **利润率检验**：毛利率 > EBITDA利润率 > 净利率（定义上始终成立）
- **倍数合理性**：
  - EV/收入：通常0.5-20x（行业差异大）
  - EV/EBITDA：通常8-25x（各行业相对一致）
  - P/E：通常10-50x（取决于增速）
- **增速-倍数相关性**：高增速通常对应高倍数
- **规模-效率权衡**：大公司往往利润率更好（规模效应）

### 常见错误

- 在公式中混用市值与企业价值
- 分子与分母使用不同时间段（LTM vs 季度）
- 将预算数值硬编码而非通过计算得出
- 硬编码输入未标注数据来源
- 包含过多缺乏明确目的的指标
- 包含不可比的公司（不同商业模式）
- 使用过时数据但未声明

## 红旗警告与警示信号

### 数据质量问题

- 时间段不一致（混用季度与年度）
- 数据缺失但无解释
- 不同数据来源间差异超过10%

### 估值红旗

- EBITDA为负的公司用EBITDA倍数估值（应改用收入倍数）
- P/E超过100x但没有超高速增长支撑
- 利润率不符合行业特征

### 可比性问题

- 财年截止日不同（造成时间错配）
- 混用纯业务公司与综合企业
- 商业模式实质不同却列为"可比"

**存疑时，排除该公司。** 3个完美可比优于6个可疑可比。

## 关键原则总结

1. **结构驱动洞见** —— 正确的表头强制正确的思考
2. **少即是多** —— 5-10个有效指标胜过20个无关指标
3. **为你的问题选指标** —— 估值分析 ≠ 效率分析
4. **统计揭示规律** —— 中位数/四分位数比均值更有洞察力
5. **透明胜于复杂** —— 简单公式人人可理解
6. **可比性为王** —— 排除优于强行纳入
7. **记录你的选择** —— 在注释部分解释选了哪些指标及原因
