# 框架参考

## 2x2矩阵：常见行业轴对

*科技/SaaS：* 产品广度 x 客户分层，集成深度 x 地理覆盖

*消费/零售：* 价格定位 x 产品范围，线上 x 线下渗透

*金融服务：* 产品复杂度 x 客户成熟度，规模 x 专业化

*医疗健康：* 服务场景 x 支付方结构，技术赋能程度 x 服务广度

*工业制造：* 定制化程度 x 规模，地理范围 x 垂直聚焦

---

### 使用指引

选择2x2矩阵轴对时：

1. **优先选择竞争格局中最具区分力的两个维度** -- 看哪些因素最能将竞争对手分成不同阵营
2. **轴对应当相互独立** -- 避免高度相关的维度（如"收入"和"市值"在同一行业往往近似）
3. **每条轴应有明确的低-高含义** -- 让读者直觉理解"左下角"和"右上角"代表什么
4. **行业未列出时** -- 观察投资者和分析师最常用来区分竞争对手的两个维度，作为轴对候选
