# 竞争格局分析

构建完整的竞争格局分析报告。这是一个两阶段流程：先界定范围并获取大纲审批，再构建内容。

## 数据来源

本技能假定**所有输入数据已提前准备好** -- 由用户提供或通过其他技能/工具获取。数据可能来自：
- 用户提供的文件（Excel/CSV/PDF），包含财务指标、市场数据、竞争对手详情
- 通过其他技能预先获取的数据（如 comps-analysis 提供估值指标）
- 用户直接输入的关键数据和定性评估

开始前，向用户确认哪些数据可用、数据在哪里。请用户提供竞争对手财务数据、市场规模数据以及任何已有的分析。

## 输出格式

本技能输出**纯文本内容**（Markdown表格和文字），适用于聊天交付、报告或文档场景。不生成Excel/PPT/Word文件。

---

## 阶段一 -- 界定分析范围

竞争分析对不同人意味着不同的事。在任何研究或内容构建之前，先询问用户确认他们真正需要什么。不要猜测 -- 一份20页的同业基准对比报告和一份5页的市场地图都叫"竞争分析"，但形态截然不同。

尽量在一轮对话中收集以下信息：

- **范围** -- 以单一目标公司为核心、围绕其展开竞争对手分析？还是多公司并排对比、没有主角？
- **竞争对手集合** -- 哪些公司纳入范围？如果用户明确指定，严格使用这些公司。如果用户说"常见对手"，先提出一组候选，请用户确认。
- **受众与深度** -- 给已经熟悉该行业的人快速概览，还是面向新人的完整入门？这决定是否需要市场规模、行业经济学和历史背景 -- 还是可以直接跳到对比部分。
- **投资语境** -- 是否需要乐观/基准/悲观情景和关键信号？仅当投资论题需要时才纳入（见步骤9）；战略审视可跳过。

如果用户上传了包含竞争对手数据的文件，在开始提取数据前，先确认各列对应哪些指标。源文件忠实度至关重要：使用原始值，不要重新计算或重新取整。

## 阶段二 -- 大纲审批后再构建

**在大纲获批之前，不要开始构建内容。** 提出章节标题和一行内容说明，向用户展示并获得确认。竞争分析报告包含10-20个相互关联的内容章节 -- 因为第4章方向错误而重建代价很大。大纲是低成本迭代点。

提出大纲时，可以向用户询问结构决策：选择哪种定位可视化方式（2x2矩阵 / 雷达图 / 分层图 -- 见步骤5），如何分组竞争对手（按商业模式 / 按客群 / 按姿态 -- 见步骤4）。这些都是用户可能有偏好的主观判断。

## 标准要求 -- 全程适用

### 提示词忠实度

用户指定的内容是要求，不是建议：
- **章节标题和名称** -- 严格使用用户原话。如果用户说"概览与竞争范围"，不要换成"2024财年竞争格局"。
- **图表 vs 表格** -- 不可互换。"图表"意味着可视化图形展示（带数据标注），"表格"意味着结构化网格。
- **完整数据序列** -- 用户列出7个竞争对手就包含全部7个；列出2015-2025就包含每一年。
- **精确数值与比率** -- "超过DoorDash 4:1、Lyft 8:1"就是这些比率，不是"7.6x Lyft"。

### 数据源质量（当来源冲突时）

1. 10-K / 年度报告（审计过的）
2. 业绩发布会 / 投资者推介材料（管理层表述）
3. 券商研报（分析师估算，适用于私有公司规模测算）
4. 行业报告（McKinsey、Gartner -- 市场规模、趋势）
5. 新闻（仅用于最新动态；需对照一手来源验证）

### 数据可比性

- 所有竞争对手指标来自同一财年；例外需明确标注（"FY24" vs "H1 2024"）
- 跨竞争对手使用相同指标定义
- 国际数据转换为美元；注明汇率和日期
- 缺失数据显示为 "-" 或 "N/A"，估算值加 "[E]" 标记 -- 绝不留空
- 每个数字附来源引用："[公司] [文件] ([日期])"

### 内容设计原则

- **标题传达洞察，而非主题标签。** "规模化领导者正在拉开与利基玩家的差距" -- 不是"竞争分析"。
- **关键信号必须量化。** "利润率低于40%" -- 不是"利润率下降"。
- **评级显示实际数值。** "●●● $160B" -- 不是仅仅"●●●"。

**数据可视化建议：**

- **图表选择原则** -- 2x2矩阵适用于两个主导竞争因子；雷达图适用于多因子对比；分层图适用于自然聚类的战略分组；价值链图适用于垂直行业；生态图适用于平台市场
- **系列数量控制** -- 超过6个系列应拆分为多个图表或改用表格
- **饼图标注** -- 馅饼图应在切片上显示百分比，而不仅在图例中
- **图例位置** -- 饼图（≤6切片）图例放右侧；折线/柱状图（≤4系列）图例放底部

**表格设计原则：**

- 表头行浅灰背景、加粗
- 数值右对齐，文字左对齐
- 留足够的单元格内间距，文字不贴边框
- 同类元素保持一致的格式规范

**色彩原则** -- 最多2-3种颜色。柔和色调 -- 深蓝、灰色、一种强调色。颜色含义贯穿全文保持一致。

参见 `references/frameworks.md` 了解2x2矩阵行业轴对参考。
参见 `references/schemas.md` 了解M&A交易表、情景分析表和内容结构示意。

### 严格 vs 弹性

| 严格执行 | 视情况灵活 |
|---|---|
| 用户指定时的精确标题/章节 | 用户未指定时的创意标题 |
| 用户说图表就图表，说表格就表格 | 未指定时的可视化类型选择 |
| 用户列出的每个竞争对手/数据点 | 未指定时的竞争对手数量 |
| 用户指定的精确数值 | 未指定精度时的取整方式 |
| 标题不应溢出 | 选择哪些维度进行对比 |

## 分析工作流程

### 步骤0 -- 行业核心指标

首先确定：这个行业真正运转的3-5个指标是什么？在每个竞争对手分析中一致使用这些指标。

| 行业 | 核心指标 |
|---|---|
| SaaS | ARR, NRR, CAC回收期, LTV/CAC, Rule of 40 |
| 支付 | GPV, 收入占比率, 附带率, 交易利润率 |
| 市场平台 | GMV, 收入占比率, 买家/卖家比率, 重复购买率 |
| 零售 | 同店销售, 库存周转, 单位面积销售额 |
| 物流 | 运量, 单位成本, 准时交付率, 产能利用率 |

未列出的行业 -- 选择投资者和运营者用于基准比较的指标。

### 步骤1 -- 市场背景

市场规模、增长率、驱动因素、阻碍因素。附来源。

正确示例："嵌入式支付市场2024年规模$80-100B，CAGR增长20-25%（McKinsey 2024）"
错误示例："市场很大且增长迅速"

### 步骤2 -- 行业经济学

描绘价值流动路径。方法取决于行业结构：
- **垂直结构** -- 价值链各环节，各环节典型利润率
- **平台/网络** -- 生态参与者，彼此间的价值流向
- **碎片化** -- 整合动态，不同规模的利润率差异

### 步骤3 -- 目标公司画像

```
| 指标 | 数值 |
|---|---|
| 收入 | $4.96B |
| 增长 | +26% YoY |
| 毛利率 | 45% |
| 盈利能力 | $373M 调整后EBITDA |
| 客户数 | 134K |
| 留存率 | 92% |
| 市场份额 | ~15% |
```

多业务线公司增加分部拆解：

```
| 分部 | 收入 | 收入YoY | 收入占比 | EBITDA | EBITDA YoY | 利润率 |
|---|---|---|---|---|---|---|
| 分部A | $25.1B | +26% | 57% | $6.5B | +31% | 26% |
| 分部B | $13.8B | +31% | 31% | $2.5B | +64% | 18% |
| 分部C | $5.1B | -2% | 12% | -$74M | -16% | -1% |
| 合计 | $44.0B | +18% | 100% | $6.5B* | - | 15% |
```
*如有公司层面成本需注明

### 步骤4 -- 竞争对手映射

按适用视角分组（如果用户未指定，可询问用户偏好）：
- 按商业模式 -- 平台型 / 垂直型 / 水平型
- 按客群 -- 企业 / 中小企业 / 消费者
- 按姿态 -- 直接竞争 / 侧翼竞争 / 新兴竞争
- 按起源 -- 在位者 /颠覆者 / 新进入者

### 步骤5 -- 定位可视化

| 类型 | 适用场景 |
|---|---|
| 2x2矩阵 | 两个主导竞争因子 |
| 雷达/蛛网图 | 多因子对比 |
| 分层图 | 自然聚类的战略分组 |
| 价值链图 | 垂直行业 |
| 生态图 | 平台市场 |

2x2矩阵的轴对选择参见 `references/frameworks.md`。

### 步骤6 -- 竞争对手深度剖析

每个竞争对手两张表。

**指标表：**
```
| 指标 | 数值 |
|---|---|
| 收入 | $X.XB |
| 增长 | +XX% YoY |
| 毛利率 | XX% |
| 市值 | $X.XB |
| 盈利能力 | $XXXM EBITDA |
| 客户数 | XXK |
| 留存率 | XX% |
| 市场份额 | ~XX% |
```

**定性表：**
```
| 类别 | 评估 |
|---|---|
| 业务 | 一句话描述其主营业务 |
| 优势 | 2-3条要点 |
| 弱点 | 2-3条要点 |
| 战略 | 当前优先事项 |
```

### 步骤7 -- 比较分析

```
| 维度 | 公司A | 公司B | 公司C |
|---|---|---|---|
| 规模 | ●●● $160B | ●●○ $45B | ●○○ $8B |
| 增长 | ●●○ +26% | ●●● +35% | ●●○ +22% |
| 利润率 | ●●○ 7.5% | ●○○ 3.2% | ●●● 15% |
```

### 步骤8 -- 战略背景

M&A交易（估值倍数、交易逻辑）、合作趋势、融资模式、监管动向。M&A交易表格式参见 `references/schemas.md`。

### 步骤9 -- 综合

**护城河评估** -- 对每个竞争对手在以下维度评级 强 / 中 / 弱：

| 护城河 | 评估要点 |
|---|---|
| 网络效应 | 用户/供应商飞轮强度；跨侧 vs 同侧效应 |
| 转换成本 | 技术集成深度、合同锁定、行为习惯 |
| 规模经济 | 规模下的单位成本优势；最低有效规模 |
| 无形资产 | 品牌、专有数据、监管许可、专利 |

**必需的综合要素：**
- 持久优势（难以复制） -- 映射到护城河类别
- 结构性弱点（难以修复）
- 当前状态 vs 发展趋势

**投资语境下**（仅当阶段一界定时确认需要）：

```
| 情景 | 概率 | 核心驱动因素 |
|---|---|---|
| 乐观 | 30% | 市场份额提升、利润率扩张 |
| 基准 | 50% | 当前趋势延续 |
| 悲观 | 20% | 竞争压力加剧、利润率压缩 |
```

完整情景分析表格式参见 `references/schemas.md`。

## 质量检查清单

完成前逐项检查：

**提示词忠实度**
- 章节标题与用户指定的完全一致，一字不差
- 图表在用户要求图表处；表格在用户要求表格处
- 用户列出的每个竞争对手/年份/数据点均已包含
- 数值和格式严格按指定呈现

**数据一致性**
- 源文件数值直接提取，不重新计算
- 同一指标在各处出现时数值相同
- 小数精度与来源保持一致

**内容质量**
- 每个数字附来源引用
- 所有指标来自同一财年周期（或已标注例外）
- 章节标题传达洞察而非主题
- 表格格式规范：数值右对齐、文字左对齐、表头加粗浅灰底
