# Markdown 输出格式标准

本文件定义三报表联动财务模型的视觉格式标准，适用于 Markdown 文本输出。确保模型专业、清晰、易于审计。

---

## 1. 数值精度

| 数据类型 | 格式 | 示例 |
|---------|------|------|
| 收入/费用（百万） | #,##0 | 12,345 |
| 每股金额 | #,##0.00 | 45.67 |
| 百分比 | 0.0% | 12.3% |
| 倍数 | 0.0x | 3.0x |
| 天数 | 0 | 45 |

---

## 2. 负值格式

负值统一使用括号表示，而非负号：

| 格式类型 | 示例 | 适用场景 |
|---------|------|---------|
| 货币负值 | (1,234) | 亏损、现金使用、债务偿还 |
| 百分比负值 | (12.3%) | 利润率下降、增长率下滑 |

**禁止使用**：负号前缀格式（如 -1,234），因为视觉上容易被忽略。

---

## 3. 视觉分隔

### 章节分隔
- 利润表各主要章节之间（毛利润、EBITDA、EBIT、EBT、净利润）使用水平分隔线（`---`）或空行分隔
- 资产负债表中流动资产、非流动资产、流动负债、非流动负债、权益各区块之间使用空行分隔
- 现金流量表中CFO、CFI、CFF各区块之间使用空行分隔

### 历史与预测分隔
- 历史期间(A)和预测期间(E)之间应有明确的视觉分隔
- 可在表格中使用额外的列间距或在文本中明确标注

### 区域标题
- 章节标题使用 `###` 级别标题
- 子章节使用 `####` 级别标题

---

## 4. 合计行格式

| 合计行类型 | 格式 |
|----------|------|
| 总计/合计行 | 加粗 + 上方空行分隔 |
| 小计行 | 加粗 |
| 检查行 | 加粗 + 标注检查状态 |

---

## 5. 余额表检查行

每个期间的资产负债表底部必须包含检查行：

```
检查行 = 资产总计 - 负债总计 - 权益总计
预期值 = 0
```

输出格式：
- 检查值 = 0 → 显示为 `**余额检查：平衡 ✓**`
- 检查值 ≠ 0 → 显示为 `**余额检查：不平衡！差额 = XXX** ⚠️`

---

## 6. 利润率行

利润率行紧接在对应利润行下方展示：

```
| 毛利润 | XXX |
| 毛利率 % | XX.X% |

| EBITDA | XXX |
| EBITDA利润率 % | XX.X% |

| EBIT | XXX |
| EBIT利润率 % | XX.X% |

| 净利润 | XXX |
| 净利润率 % | XX.X% |
```

利润率格式：
- 标注单位为百分比(%)
- 数值格式：保留1位小数（如 12.3%）

---

## 7. 信用指标格式

信用指标在资产负债表下方独立区块展示：

```markdown
### 信用指标

| 指标 | FY2024A | FY2025E | FY2026E | FY2027E | FY2028E |
|------|---------|---------|---------|---------|---------|
| 总债务/EBITDA | 3.0x | 2.8x | ... | ... | ... |
| 净债务/EBITDA | 2.5x | 2.2x | ... | ... | ... |
| 利息覆盖率 | 5.0x | 5.5x | ... | ... | ... |
```

信用指标数值格式：
- 倍数类：一位小数 + "x"后缀（如 3.0x）
- 百分比类：一位小数（如 35.0%）
- 比率类：一位小数（如 0.5）

---

## 8. 阈值标记（信用指标）

根据指标值与契约阈值/行业标准的关系进行标记：

| 标记 | 含义 | 杠杆指标判断 | 覆盖率指标判断 |
|------|------|-------------|-------------|
| 🟢 绿色 | 健康/安全 | 总债务/EBITDA < 3.0x | 利息覆盖率 > 4.0x |
| 🟡 黄色 | 警告/需关注 | 总债务/EBITDA 3.0x - 5.0x | 利息覆盖率 2.0x - 4.0x |
| 🔴 红色 | 危险/违约风险 | 总债务/EBITDA > 5.0x | 利息覆盖率 < 2.0x |

**注意**：上述阈值仅为通用参考值。如用户提供了特定契约阈值，优先使用用户提供值。

---

## 9. 错误标记

- 任何计算错误 → `**错误：XXX** ⚠️` 标记
- 除零错误 → `N/A` 或 `-` 标注说明

### 余额表检查
- 检查值 = 0 → `**平衡 ✓**`
- 检查值 ≠ 0 → `**不平衡！⚠️**`

### 现金核对
- 检查值 = 0 → `**核对通过 ✓**`
- 检查值 ≠ 0 → `**核对失败！⚠️**`

### 情景层次检查
- 层次关系正确 → 无特殊标记
- 层次关系违反 → `⚠️ 层次关系违反` 标记

---

## 10. 利润率合理性标记

利润率必须满足定义上的层次关系：

```
毛利率 > EBITDA利润率 > EBIT利润率 > 净利润率
```

标记规则：
- 层次关系正确 → 无标记（通过）
- 层次关系违反 → `⚠️ 利润率层次异常` 标记
  - 可能原因：费用归类错误、税费计算错误、非营业项遗漏

### 常见利润率异常诊断

| 异常情况 | 可能原因 |
|---------|---------|
| 毛利率 < EBITDA利润率 | COGS计算有误或EBITDA定义不一致 |
| EBIT利润率 > EBITDA利润率 | 折旧/摊销金额符号错误 |
| 净利润率 > EBIT利润率 | 非营业收入遗漏或利息计算错误 |

---

## 11. 表格设计原则

- 表头行加粗
- 数值右对齐，文字左对齐
- 留足够的单元格内间距（在Markdown中通过合理列对齐实现）
- 同类元素保持一致的格式规范
- 列标题使用 `|` 分隔的Markdown表格格式
- 历史期间标注"A"后缀：FY2024A
- 预测期间标注"E"后缀：FY2025E
