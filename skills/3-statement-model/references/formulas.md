# 公式参考

本文件汇总三报表联动财务模型中使用的所有核心公式、勾稽关系和报表结构。

---

## 1. 核心勾稽关系

三报表之间必须始终成立的勾稽关系：

| 勾稽关系 | 公式 | 预期结果 |
|---------|------|---------|
| 资产负债表平衡 | 资产 - 负债 - 权益 | = 0 |
| 现金核对 | CF期末现金 - BS现金 | = 0 |
| 月度与年度现金一致 | 月度期末现金 - 年度期末现金 | = 0 |
| 净利润联动 | IS净利润 - CF起始净利润 | = 0 |
| 留存收益滚存 | 前期RE + NI + 股份报酬 - 股利 - BS期末RE | = 0 |
| 权益筹资核对 | 普通股/资本溢价变动(BS) - 权益发行(CFF) | = 0 |
| 第0年权益核对 | 第0年筹集权益 - 第1年期初权益资本 | = 0 |

---

## 2. 毛利润计算

```
毛利润 = 营业收入 - 营业成本（COGS）
毛利率 = 毛利润 / 营业收入
```

注意：
- COGS通常由营业收入乘以COGS占收入比例驱动：`COGS = 营业收入 * COGS占比`
- 预测期间毛利率可能随假设变化，但公式结构必须一致

---

## 3. 利润率公式

| 利润率 | 公式 | 说明 |
|-------|------|------|
| 毛利率 | 毛利润 / 营业收入 | 定价能力与生产效率 |
| EBITDA利润率 | EBITDA / 营业收入 | 核心营业盈利能力 |
| EBIT利润率 | EBIT / 营业收入 | 扣除折旧摊销后的营业盈利能力 |
| 净利润率 | 净利润 / 营业收入 | 底线盈利能力 |

利润率合理性规则（定义上恒成立）：
```
毛利率 > EBITDA利润率 > EBIT利润率 > 净利润率
```

如违反此规则，说明模型中存在错误。

---

## 4. 信用指标公式

| 指标 | 公式 | 说明 |
|------|------|------|
| 总债务/EBITDA | 总债务 / LTM EBITDA | 杠杆倍数 |
| 净债务/EBITDA | (总债务 - 现金) / LTM EBITDA | 扣除现金后的杠杆 |
| 利息覆盖率 | EBITDA / 利息支出 | 债务偿付能力 |
| 债务/总资本 | 总债务 / (总债务 + 权益) | 资本结构 |
| 债务/权益 | 总债务 / 总权益 | 财务杠杆 |
| 流动比率 | 流动资产 / 流动负债 | 短期流动性 |
| 速动比率 | (流动资产 - 存货) / 流动负债 | 即时流动性 |

信用指标层次验证（跨情景）：
- 杠杆类：上行情景 < 基础情景 < 下行情景（越低越好）
- 覆盖率类：上行情景 > 基础情景 > 下行情景（越高越好）
- 流动性类：上行情景 > 基础情景 > 下行情景（越高越好）

## 5. 预测公式

### 收入预测
```
预测收入(N) = 前期收入(N-1) * (1 + 收入增长率)
收入增长率(N) = 预测收入(N) / 前期收入(N-1) - 1
```

### 营业成本预测
```
COGS(N) = 预测收入(N) * COGS占收入比例
```

### 营业费用预测
```
销售费用(N) = 预测收入(N) * 销售费用占收入比例
研发费用(N) = 预测收入(N) * 研发费用占收入比例
管理费用(N) = 预测收入(N) * 管理费用占收入比例
股份报酬(N) = 预测收入(N) * 股份报酬占收入比例
```

**关键**：营业费用基于营业收入驱动，不是基于毛利润。

### EBITDA计算
```
EBITDA = 毛利润 - 销售费用 - 研发费用 - 管理费用 + 其他调整项
或
EBITDA = EBIT + 折旧 + 摨销
```

### EBIT计算
```
EBIT = 毛利润 - 销售费用 - 研发费用 - 管理费用 - 其他营业费用
或
EBIT = EBITDA - 折旧 - 摨销
```

### 税费计算
```
税费 = EBT * 税率
EBT = EBIT - 利息支出 - 其他非营业项
净利润 = EBT - 税费
```

当EBT <= 0时，税费 = 0。

## 6. 营运资金公式

### 营运资金定义
```
净营运资金(NWC) = 流动资产(不含现金) - 流动负债(不含短期债务)
```

### 天数指标
```
DSO（应收账款周转天数） = 应收账款 / (营业收入 / 365)
DIO（存货周转天数） = 存货 / (COGS / 365)
DPO（应付账款周转天数） = 应付账款 / (COGS / 365)
```

### 营运资金变动（现金流量表）
```
营运资金变动 = 前期NWC - 当期NWC
```

注意符号：
- 流动资产增加 → 现金使用 → CFO中为负值
- 流动负债增加 → 现金来源 → CFO中为正值

### 预测营运资金科目
```
应收账款 = DSO * (营业收入 / 365)
存货 = DIO * (COGS / 365)
应付账款 = DPO * (COGS / 365)
```

## 7. 折旧摊销公式

### PP&E滚存
```
期末PP&E = 期初PP&E + 资本支出 - 折旧 - 处置
```

### 折旧计算
```
折旧 = 期初PP&E * 折旧率
或（直线法）
折旧 = (资产原值 - 残值) / 使用年限
```

### 摨销计算
```
摨销 = 期初无形资产 * 摨销率
或（直线法）
摨销 = 无形资产原值 / 摨销年限
```

### 资本支出
```
资本支出 = 营业收入 * 资本支出占收入比例
```

---

## 8. 债务公式

### 债务滚存
```
期末债务 = 期初债务 + 新发行 - 偿还
```

### 利息支出（注意循环引用）
```
利息支出 = 平均债务余额 * 利率
平均债务余额 = (期初债务 + 期末债务) / 2
```

循环：利息支出 → 净利润 → 现金 → 债务余额 → 利息支出

### 强制偿还与可选偿还
- 强制偿还：按合同约定的时间表
- 可选偿还：利用多余现金偿还（需添加现金扫除公式）

---

## 9. 留存收益

### 留存收益滚存
```
期末留存收益 = 期初留存收益 + 净利润 + 股份报酬 - 股利 - 其他调整
```

### 股利计算
```
股利 = 净利润 * 股利支付率
或
股利 = 固定金额（按公司政策）
```

---

## 10. NOL净营业亏损

### NOL滚存
```
期末NOL = 期初NOL + 本期新增亏损 - 本期利用
```

### NOL产生条件
```
当 EBT < 0 时：本期新增亏损 = |EBT|
当 EBT >= 0 时：本期新增亏损 = 0
```

### NOL利用限制
```
最大NOL利用 = EBT的80%（2017年后联邦限制）
实际利用 = min(可用NOL, 最大NOL利用)
```

### DTA（递延税资产）
```
DTA = NOL余额 * 税率
```

### 税费调整
```
现金税费 = max(EBT * 税率 - NOL利用 * 税率, 0)
税费（报表）= EBT * 税率
递延税 = 税费（报表）- 现金税费
```

## 11. 报表结构

### 利润表结构（自上而下）
```
营业收入
(-) 营业成本(COGS)
= 毛利润
毛利率 %（毛利润/营业收入）

(-) 销售费用
(-) 研发费用
(-) 管理费用
(+) 股份报酬（如单独列出则为负值加回）
= EBITDA
EBITDA利润率 %（EBITDA/营业收入）

(-) 折旧
(-) 摨销
= EBIT
EBIT利润率 %（EBIT/营业收入）

(-) 利息支出
(+) 利息收入
(+) 其他非营业收入
(-) 其他非营业支出
= EBT（税前利润）

(-) 税费
= 净利润
净利润率 %（净利润/营业收入）
```

### 资产负债表结构
```
流动资产：
  现金及等价物
  应收账款
  存货
  其他流动资产
= 流动资产合计

非流动资产：
  PP&E（净值）
  无形资产（净值）
  递延税资产
  其他非流动资产
= 非流动资产合计

= 资产总计

流动负债：
  应付账款
  短期债务
  其他流动负债
= 流动负债合计

非流动负债：
  长期债务
  递延税负债
  其他非流动负债
= 非流动负债合计

= 负债总计

权益：
  普通股/资本溢价
  留存收益
  其他权益项
= 权益总计

= 负债 + 权益总计  ← 必须等于资产总计
```

### 现金流量表结构
```
经营活动现金流(CFO)：
  净利润
  (+) 折旧与摨销
  (+) 股份报酬
  (+) 其他非现金调整
  (-) 应收账款变动（增加为负）
  (-) 存货变动（增加为负）
  (+) 应付账款变动（增加为正）
  (+) 其他营运资金变动
= CFO合计

投资活动现金流(CFI)：
  (-) 资本支出
  (+) 资产处置收入
  (+) 其他投资活动
= CFI合计

筹资活动现金流(CFF)：
  (+) 债务发行
  (-) 债务偿还
  (+) 权益发行
  (-) 股利支付
  (+) 其他筹资活动
= CFF合计

= 现金变动合计
期初现金
= 期末现金  ← 必须等于BS现金
```

## 12. 检查公式

### 余额表平衡检查
```
检查值 = 资产总计 - 负债总计 - 权益总计
预期：每个期间 = 0
```

### 现金核对检查
```
检查值 = CF期末现金 - BS现金及等价物
预期：每个期间 = 0
```

### 净利润联动检查
```
检查值 = IS净利润 - CF净利润
预期：每个期间 = 0
```

### 留存收益检查
```
检查值 = 期初RE + 净利润 + 股份报酬 - 股利 - 期末RE(BS)
预期：每个期间 = 0
```

### 营运资金一致性检查
```
应收账款变动 = BS应收账款(N) - BS应收账款(N-1)
存货变动 = BS存货(N) - BS存货(N-1)
应付账款变动 = BS应付账款(N) - BS应付账款(N-1)

验证：
CF应收账款变动 = -(BS应收账款变动)  （资产增加为现金使用，CFO中为负）
CF存货变动 = -(BS存货变动)  （同上）
CF应付账款变动 = +(BS应付账款变动)  （负债增加为现金来源，CFO中为正）
```

### 债务一致性检查
```
BS债务变动 = BS总债务(N) - BS总债务(N-1)
CF债务净变动 = 债务发行 - 债务偿还

验证：
BS债务变动 = CF债务净变动
```

### PP&E一致性检查
```
BS PP&E变动 = BS PP&E(N) - BS PP&E(N-1)
预期PP&E变动 = 资本支出 - 折旧 - 处置

验证：
BS PP&E变动 = 预期PP&E变动（考虑处置等其他因素）
```
