# 财报预览分析

在公司发布季度财报之前，构建完整的预览分析——包含一致预期、关键指标框架、情景分析和催化剂清单。

## 工作流程

### 步骤 1：收集背景信息

需要用户提供或自行准备以下信息：

- 识别公司和报告季度
- 一致预期数据（收入、EPS、关键分部指标）——由用户提供或通过其他 skill 获取
- 财报日期和时间（盘前 vs. 盘后）
- 公司上一季度的财报电话会议要点（管理层指引和关键评论）

**注意**：此步骤不自动拉取数据，数据需由用户提前准备或通过其他 skill 提供。

### 步骤 2：关键指标框架

根据公司所在行业，构建"关注什么"框架：

**财务指标：**
- 收入 vs. 一致预期（总量和分部）
- EPS vs. 一致预期
- 利润率（毛利率、营业利润率、净利率）——扩张还是收缩？
- 自由现金流
- 前瞻指引 vs. 一致预期

**运营指标**（按行业定制）：
- 科技/SaaS：ARR、净留存率、RPO、客户数
- 零售：同店销售、客流、客单价
- 工业：在手订单、订单出货比、价格 vs. 量
- 金融：净息差、信贷质量、贷款增长、手续费收入
- 医疗：处方量、患者就诊量、管线进展

### 步骤 3：情景分析

构建3个情景及股价影响：

| 情景 | 收入 | EPS | 关键驱动 | 股价反应 |
|------|------|-----|----------|----------|
| 牛市 | | | | |
| 基准 | | | | |
| 熊市 | | | | |

对每个情景，说明：
- 运营层面需要发生什么
- 管理层怎样的措辞会暗示这个情景
- 历史背景——该股在类似财报后如何反应

### 步骤 4：催化剂清单

识别3-5个决定股价反应的关键因素：

1. [指标] vs. [一致预期/私下传闻数字] — 为什么重要
2. [指引项目] — 买方期望听到什么
3. [叙事转变] — 任何战略变化、并购、重组

### 步骤 5：输出

一页式财报预览，包含：
- 公司、季度、财报日期
- 一致预期数据表
- 关键关注指标（按重要性排序）
- 牛/基/熊情景表
- 催化剂清单
- 交易设定：近期股价表现、期权隐含波动

格式：简洁的 Markdown 文本。

## 重要说明

- 一致预期会变动——注明数据来源和日期
- 买方私下传闻数字往往比公开发布的一致预期更有参考价值
- 历史财报反应有助于校准预期（可搜索"[公司] 财报反应历史"）
- 期权隐含波动告诉你市场的预期——与你的情景做对比
